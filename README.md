# InOneLine

**InOneLine** — бесплатное приложение для Windows 10/11 x64 для стриминговых аукционов: список лотов, ставки Twitch и DonationAlerts, мультичат Twitch + YouTube, таймер, взвешенное колесо, музыка и виджеты OBS.

## Скачать

**[Скачать InOneLine 1.0.11 для Windows](https://github.com/ALL-EX-E/InOneLine/releases/download/v1.0.11/InOneLine_Setup_1.0.11.exe)** · [Страница выпуска](https://github.com/ALL-EX-E/InOneLine/releases/tag/v1.0.11) · [Контрольные суммы](./SHA256SUMS.txt).

Для установки не нужны Python и среда разработки. Если Windows предупреждает о неподписанном приложении, проверьте источник и SHA‑256 установщика.

## Возможности

- Основной список: поиск, сортировка, баллы, редактирование, архив, импорт CSV и совместная XLSX-таблица. Публичный список: экспорт CSV, JSON и XLSX, подключение публичной таблицы.
- Карточки с названием, датой, статусом, кооперативом и отзывом, выбор текущей записи для оверлея, восстановление из архива и подтверждаемое удаление.
- Аукцион по максимальной сумме или на взвешенном колесе, в том числе с выбыванием. Временные лоты, ручные и внешние ставки, пауза, продление таймера, дополнительное время, подтверждение победителя и история.
- Локальный RNG, Random.org и Random.org+ при настроенном подключении, сохранённые данные проверки результата.
- Настройка вращения и центра колеса, оформление контура, подпись лота под стрелкой, отображение шансов; текущие ставки/события и автопрокрутка списка лотов в OBS.
- Награды за баллы канала Twitch и пожертвования DonationAlerts, конвертация единиц, отложенные начисления и защита от повторных событий.
- Мультичат Twitch + YouTube в приложении и OBS: единая лента по времени, аватары, эмодзи, удаления, независимое оформление платформ и управление их выводом в OBS.
- Основной оверлей и самостоятельные OBS-источники списка, совместной области списка/чата, таймера, лотов аукциона, правил, колеса и плеера. Оформление, поддерживаемые медиафоны и предпросмотр.
- Текущая запись, информационный блок, фон, рамки игрового окна и веб-камеры; самостоятельное сохранение секций. Совместная область списка/чата с разделением или замещением и вызовом списка командой Twitch.
- Локальная музыка, порядок по алфавиту или перемешивание, повтор трека, обложки, саундтреки аукциона/колеса и вывод звука через приложение или браузерный источник OBS.
- Редактор шаблонов правил, журнал, резервные копии базы и полные резервные копии с восстановлением.
- Общая медиатека, выбор поддерживаемого хранения файлов, обновление разделов через F5 и сохранение настроек интерфейса.

[Все возможности и условия работы](./docs/FEATURES.md).

## Готовится 1.0.12

После 1.0.11 приняты и включены в основную версию кода:

- Прямое подключение к чату конкретной трансляции YouTube по HTTPS-ссылке без платного API и без OAuth.
- Общая лента Twitch + YouTube в операторском окне и одном OBS-источнике с сортировкой сообщений по времени.
- Аватары, нативные emoji YouTube, удаления сообщений и сохранение уже показанной ленты при переподключении.
- Независимое оформление Twitch и YouTube, отдельный допуск каждой платформы в OBS и общие фон/контур мультичата.
- Настройки собраны в три блока: «Общие настройки», «Twitch», «YouTube»; параметры отключённого сервиса скрываются, а подключение остаётся доступно.

[Заметки к кандидату 1.0.12](./RELEASE_NOTES_1.0.12.md) · [Документация](./docs/README.md). До ручной проверки нового установщика актуальным публичным выпуском остаётся 1.0.11.

Локальный API OBS по умолчанию доступен на `127.0.0.1`. Управление аудио через OBS и вывод через браузерную страницу — разные режимы.

## Развитие

Разработка новых функций **приостановлена пользователем**. Отложенные идеи сохранены в [рабочем документе](./docs/Правила_и_дальнейший_распорядок_работ.md); повторный круг автоматически не начинается.

В описании используются понятия **«аукцион», «лот», «ставка», «результат»**, но часть полей и статусов унаследована от исходной модели. **Универсальная поддержка произвольных категорий лотов пока не реализована.** Это [возможное направление](./docs/FUTURE_GENERAL_AUCTIONS.md). Чат Kick/VK Video Live, другие платформы пожертвований и публичный веб-сервис также не заявляются как готовые функции.
