# InOneLine

**InOneLine** — Windows-приложение для стримеров: список игр, аукцион, weighted wheel, музыкальный плеер и OBS Browser Sources в одном приложении.

## Скачать и установить

1. Откройте страницу [Releases](../../releases).
2. Скачайте **`InOneLine_1.0.8_MAINTENANCE_FINAL.exe`** из последнего принятого maintenance-релиза **v1.0.8-maintenance-2026-10-01**.
3. Запустить установщик.
4. После установки запустите InOneLine через ярлык или меню «Пуск».

Для обычной установки не нужны Python, Git или другие дополнительные программы.

> Установщик не подписан публично доверенным Authenticode-сертификатом, поэтому Windows может показать SmartScreen/«Неизвестный издатель». Это предупреждение связано с отсутствием платной публично доверенной цифровой подписи и само по себе не означает, что файл повреждён. Сначала убедитесь, что installer скачан с официальной страницы Releases этого репозитория, и при необходимости сверьте SHA-256 ниже. Если SmartScreen предлагает продолжить, выберите **«Подробнее» → «Выполнить в любом случае»**. В окне UAC с «Неизвестным издателем» выберите **«Да»** только после проверки источника/хэша. Отключать SmartScreen, Smart App Control, антивирус или другую защиту Windows для установки InOneLine не требуется.

## Основные возможности

- управление основным и публичным списком игр;
- аукцион и отдельный список лотов;
- определение победителя по максимальной сумме;
- weighted wheel и формат «Выбывание»;
- пользовательское статичное/анимированное изображение в центре колеса;
- таймеры и дополнительное время при ничьей;
- музыка аукциона/колеса через OBS Browser Source;
- Music Player с библиотекой, очередью, MP3/WAV/OGG и сохранением позиции;
- отдельный Music Player OBS Browser Source с обложкой и Spectrum;
- история аукционов и проверяемые RNG snapshots;
- интеграции Twitch и DonationAlerts;
- семь встроенных OBS Browser Sources;
- экспорт CSV / JSON / Excel;
- резервное копирование и полное восстановление данных;
- условное скрытие логически неприменимых настроек без скрытия временно заблокированных действий.

## OBS

Адреса Browser Sources и связанные настройки доступны внутри программы. Локальный API по умолчанию работает через `127.0.0.1`.
