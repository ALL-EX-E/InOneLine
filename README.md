# InOneLine

**InOneLine** — бесплатное приложение для Windows, с которым можно вести стриминговый аукцион, принимать события Twitch и DonationAlerts и показывать ход эфира в OBS.

## Скачать

Откройте [последний выпуск на GitHub](https://github.com/ALL-EX-E/InOneLine/releases/latest) и скачайте Windows-установщик из раздела Assets. Для установки не нужны Python и среда разработки. Если Windows предупреждает о неподписанном приложении, проверьте источник и SHA‑256 установщика.

## Возможности

- Основной и публичный списки записей, сортировка, архив, импорт и экспорт CSV, JSON и XLSX.
- Аукцион по максимальной сумме или на взвешенном колесе, включая режим выбывания. Временные лоты, ставки, таймеры, история и проверяемые снимки результатов колеса.
- Интеграции Twitch и DonationAlerts, Twitch-чат и защита от повторного начисления.
- Основной OBS-оверлей и отдельные источники браузера для списка, чата, таймеров, правил и музыкального плеера. Настройки оформления, медиафоны и предпросмотр.
- Резервное копирование и восстановление, журнал событий.

## Что нового в 1.0.10

- В OBS список можно показывать постоянно, скрыть или вызывать командой Twitch. У выезда четыре направления. При времени показа 0 секунд повторная команда скрывает список, а при положительном времени продлевает показ.
- Список и Twitch-чат можно вывести отдельно или совместно. В режиме «Разделение области» список занимает свободную верхнюю часть и перекрывает заполненный чат без сжатия его области. В «Замещении области» список закрывает всю общую область, а после ухода снова виден актуальный чат.
- В «Стрим / OBS» у текущей записи, списка, игрового окна, веб-камеры, фона и информационного блока свои кнопки сохранения. Для игрового окна исправлено отображение выреза в формате 4:3.
- Улучшено обновление сообщений Twitch в OBS при задержке ответов и анимации списка.

[Заметки к версии 1.0.10](./RELEASE_NOTES_1.0.10.md) · [Документация](./docs/README.md)

Локальный API OBS по умолчанию доступен на `127.0.0.1`. Управление аудио через OBS и вывод через браузерную страницу — разные режимы.

## Развитие

В публичном описании используются нейтральные понятия **«аукцион», «лот», «ставка», «результат»**. Часть полей и статусов текущей версии унаследована от первоначальной модели данных. **Универсальная поддержка произвольных категорий лотов пока не реализована.** Это [возможное направление будущей разработки](./docs/FUTURE_GENERAL_AUCTIONS.md), для которого потребуется отдельное согласование и проверка.
