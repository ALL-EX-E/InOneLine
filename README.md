# InOneLine

**InOneLine** — Windows-приложение для стримеров: список игр, аукцион, колесо выбора и OBS-оверлеи в одном приложении.

## Скачать и установить

1. Откройте страницу [Releases](../../releases).
2. Скачайте файл **`InOneLine_Setup_1.0.0.exe`**.
3. **Запустите установщик.**
4. Следуйте подсказкам установщика.
5. После установки запустите **InOneLine** через ярлык на рабочем столе или через меню «Пуск».

Для обычной установки **не нужны Python, Git или другие дополнительные программы**.

> **Важно:** установщик InOneLine не подписан сертификатом Authenticode публичного доверия. Такие сертификаты требуют платного оформления, а InOneLine принципиально распространяется бесплатно, поэтому проект не планирует покупать сертификат только ради снятия предупреждения Windows. Из-за отсутствия подписи Windows может показать Microsoft Defender SmartScreen или окно с «Неизвестным издателем». Это ожидаемо для неподписанного установщика и само по себе не означает, что файл вредоносный. Ниже есть пошаговая инструкция, что делать в таком случае.

## Если Windows показывает предупреждение при установке

Поскольку InOneLine распространяется бесплатно и не использует платный сертификат Authenticode, Windows может предупредить о запуске приложения от неизвестного издателя.

Если вы скачали установщик **с официальной страницы Releases этого репозитория**, действуйте так:

1. Запустите `InOneLine_Setup_1.0.0.exe`.
2. Если появилось синее окно **«Windows защитила ваш компьютер»** / **Microsoft Defender SmartScreen**, нажмите **«Подробнее»** (`More info`).
3. После этого нажмите **«Выполнить в любом случае»** (`Run anyway`).
4. Если Windows затем покажет системный запрос контроля учётных записей с **«Неизвестным издателем»**, проверьте имя файла и нажмите **«Да»**, чтобы разрешить запуск установщика.
5. Продолжите обычную установку.

Предупреждение появляется потому, что файл не подписан доверенным сертификатом издателя. Для дополнительной проверки можно сравнить SHA-256 установщика с официальным значением ниже.

> На некоторых компьютерах с Windows 11 функция Smart App Control или политика организации может полностью блокировать запуск неизвестного неподписанного приложения и не показывать кнопку «Выполнить в любом случае». В такой ситуации не рекомендуется отключать системную защиту только ради запуска InOneLine.

## Первый запуск

После запуска откроется главное окно InOneLine. Можно сразу работать со списком игр и основными функциями программы.

Интеграции Twitch, DonationAlerts и OBS настраиваются внутри самой программы. Для обычной работы с InOneLine не требуется вручную редактировать файлы программы или выполнять команды в PowerShell.

## Основные возможности

- управление списком игр и публичным списком;
- проведение аукциона с рабочим списком лотов;
- определение победителя по максимальной сумме;
- weighted wheel с вероятностями, основанными на весах лотов;
- таймеры проведения и дополнительное время при ничьей;
- история аукционов и принятых событий;
- интеграции Twitch и DonationAlerts;
- пять встроенных OBS Browser Sources;
- экспорт CSV / JSON / Excel и Pointauc-совместимые сценарии;
- резервное копирование и восстановление данных.

## OBS

InOneLine предоставляет пять встроенных Browser Sources для OBS.

Адреса Browser Sources и связанные настройки доступны внутри программы. Локальный API работает через `127.0.0.1`, то есть предназначен для работы на вашем компьютере.

## Для разработчиков

Этот раздел нужен только тем, кто хочет запускать InOneLine непосредственно из исходного кода. Для обычной установки он не требуется.

Требования:

- Windows 10/11 x64;
- Python, совместимый с `requirements.txt`;
- зависимости из `requirements.txt`.

Типовой запуск:

```powershell
python -m pip install -r requirements.txt
python app.py
```

Также в репозитории сохранены `install_python.bat` и `run.bat`.
