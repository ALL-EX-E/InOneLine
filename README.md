# InOneLine

**InOneLine** — бесплатное Windows-приложение для проведения стриминговых аукционов: список записей и лотов, ставки, колесо, таймеры, музыкальный плеер и виджеты OBS.

## Скачать

Официальные проверенные версии публикуются на [GitHub Releases](../../releases). Для установки не нужны Python или среда разработки. При предупреждении Windows о неподписанном приложении сначала проверьте источник и SHA-256, не отключайте защиту.

## Возможности 1.0.8

- Ведение основного и публичного списка, сортировка, архив и обмен CSV / JSON / XLSX.
- Аукционы по максимальной сумме и с использованием взвешенного колеса, включая режим выбывания.
- Временные лоты, работа со ставками и баллами, таймеры, подтверждение результата и история.
- Интеграции Twitch и DonationAlerts в поддерживаемых сценариях и защита от повторного начисления.
- OBS Browser Sources, предпросмотр правил и шаблонов, медиафоны, музыкальный плеер.
- Полное резервное копирование и восстановление, журнал событий и проверяемые RNG-снимки.

Локальный API OBS по умолчанию доступен на `127.0.0.1`. Управление аудио через OBS и вывод через браузерную страницу — разные режимы.

## Развитие

В публичном описании используются нейтральные понятия **«аукцион», «лот», «ставка», «результат»**. Часть полей и статусов текущей версии унаследована от первоначальной модели данных. **Универсальная поддержка произвольных категорий лотов пока не реализована.** Это [возможное направление будущей разработки](./docs/FUTURE_GENERAL_AUCTIONS.md), для которого потребуется отдельное согласование и проверка.

## Исходники и безопасность

[Документация](./docs/README.md) · [Лицензия](./LICENSE) · [История выпусков](../../releases). Каждый опубликованный установщик следует проверять по SHA-256 соответствующего релиза. Для запуска из исходников в Windows 10/11 x64:

```powershell
python -m pip install -r requirements.txt
python app.py
```
