# InOneLine 1.0.13

Выпуск исправляет журнал действий после первой установки и при работе с музыкальным плеером и подключениями Twitch.

## Журнал

- Автоматическая инициализация настроек музыкального плеера и задержки мультичата при первом запуске больше не создаёт строки, выглядящие как действия пользователя.
- Реальные изменения музыкального плеера записываются и становятся видны при открытии вкладки «Журнал» без ручного обновления F5.
- Явные подключения, переподключения, включения, отключения и удаления Twitch и DonationAlerts отображаются в журнале.
- В журнал подключения попадают только пользовательские сведения о состоянии и аккаунте; токены, пароли и другие секреты не записываются.
- Обычное окно журнала показывает до 2500 последних событий, а поиск продолжает работать по всей истории.

## Совместимость

Схема базы остаётся **21**. Существующие данные, настройки, подключения, музыка, OBS-источники и аукционы сохраняются при обновлении с 1.0.12.

## Установка и проверка

Для Windows 10/11 x64. Перед обновлением рекомендуется создать полную резервную копию в настройках. Публикация выполняется только после полного native Windows CI, контрольного скачивания файлов и отдельной ручной приёмки точного установщика 1.0.13.
