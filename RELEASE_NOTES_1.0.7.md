# InOneLine 1.0.7

## D26 — Музыкальный плеер

- Добавлена отдельная вкладка «Музыка» с независимым музыкальным плеером.
- Поддерживаются MP3, WAV и OGG, managed-копии в `data\music` и ссылки на исходные файлы.
- Импорт музыки дедуплицируется по имени файла без учёта регистра: при попытке добавить external-дубликат новая строка не создаётся; одно совпадение автоматически выделяет существующий трек, несколько совпадений только перечисляются в уведомлении без навигации по списку; существующая external-запись при выборе «Копировать в программу» переводится в managed с сохранением того же ID.
- Сохраняются текущий трек, позиция, порядок воспроизведения, режим, repeat, громкость, mute и маршрут вывода.
- После нового запуска приложение никогда не начинает музыку автоматически: сохранённый трек восстанавливается в состоянии Pause.
- Режимы порядка: «По алфавиту» и «Перемешать»; «Повторять текущий трек» работает независимо от порядка.
- Поиск фильтрует только видимый список и не изменяет очередь.

## AudioCoordinator

- Music Player использует существующий AudioCoordinator как единую власть над слышимым музыкальным источником.
- Аукцион и колесо приостанавливают Music Player только тогда, когда у события действительно есть доступный незаглушённый soundtrack.
- Mute события немедленно возвращает Music Player; снятие mute во время активного события снова передаёт ownership soundtrack без перезапуска его транспорта.
- Между раундами D21 «Выбывание» Music Player возобновляется.
- Завершение таймера возвращает Music Player сразу, не ожидая подтверждения победителя.
- При ничьей позиция soundtrack максимальной суммы сохраняется и продолжается с той же точки при запуске дополнительного времени.

## Soundtrack

- Аукцион и колесо используют общий каталог `data\soundtrack`, сохраняя независимые выбранные файлы.
- Soundtrack аукциона — один выбранный зацикленный файл; старый playlist/checkbox «Зациклить выбранный трек» больше не используется.
- Managed-каталоги D26 являются источником истины: вручную добавленный поддерживаемый файл появляется после refresh, удалённый managed-файл исчезает из библиотеки.
- Для совпадающего имени при копировании пользователь явно выбирает: использовать существующий, заменить, сохранить отдельную копию или отменить.
- Потерянные внешние soundtrack не создают отдельный recovery UI.

## OBS Music Player Overlay

- Music Player получил отдельный Browser Source: `/music-player-overlay`.
- Вывод звука «В приложении / Через OBS Browser Source» независим от показа визуальной плашки.
- Плашка содержит квадратную обложку, строку «Исполнитель - Название трека» и аудиореактивный Spectrum.
- FIX6: восстановлена валидная виниловая заглушка для треков без обложки; preview получил гарантированную беззвучную анимацию Spectrum; внешняя и cover-рамки получили скругления и безопасные боковые отступы; тень текста стала резче, а marquee резервирует место под тень по краям.
- FIX7: виниловая заглушка перерисована ближе к утверждённому референсу без светлой дуги; четыре направленные тени текста заменены на ровную обводку символов и компактную тень без острых выступов; синтетический Spectrum в preview заменён на плавную демонстрационную частотную форму, при этом реальный OBS-анализатор не менялся.
- FIX8: отказ от виниловой заглушки — для треков без embedded-обложки используется светящийся значок музыкальной ноты в цвет рамок; preview снова анализирует реальный текущий трек тем же WebAudio AnalyserNode, что и OBS overlay, но выводит его через нулевой gain и остаётся беззвучным.
- FIX9: preview показывает подсказку «Включите музыку в плеере и нажмите на предпросмотр, чтобы увидеть анимацию.» когда музыка не запущена или браузер заблокировал реальный WebAudio-анализ; если Spectrum уже работает, подсказка не показывается. После запуска музыки и пользовательского клика AudioContext/аудиотранспорт разблокируются, Spectrum использует реальный текущий трек, а preview остаётся беззвучным. В обычном браузерном URL используется эквивалентная подсказка с формулировкой «нажмите на окно»; в OBS при работающем анализаторе подсказка не показывается.
- FIX10: отображение preview больше не ждёт завершения браузерного audio.play()/AudioContext.resume(): плашка и подсказка выводятся немедленно, аудиоанализ запускается отдельно с таймаутами, поэтому заблокированный Chrome/Edge не может оставить предпросмотр полностью белым. При необходимости клик по видимой плашке или подсказке повторяет разблокировку WebAudio.
- При отсутствии embedded-обложки используется светящийся значок музыкальной ноты в цвет рамок.
- Обложка заполняет квадрат по принципу cover + center; лишнее симметрично обрезается.
- Длинный текст автоматически прокручивается только при нехватке ширины.
- Плашка адаптивная: занимает 100% ширины Browser Source и сохраняет пропорцию 40:9 при любом разрешении.
- Поддерживаются прозрачный/цветной фон, цвет текста, рамок и Spectrum, подбор фона/рамок по обложке и автоматическая защита контраста.
- Режимы показа: «Не показывать», «При смене трека», «Показывать постоянно».
- Анимации: проявление или выезд слева/справа/сверху/снизу.
- Preview всегда без дополнительного слышимого аудио.
- На вкладке «Музыка» есть быстрые кнопки URL/preview; полные настройки находятся в «Стрим / OBS» и используют тот же центральный механизм.
