# InOneLine 1.0.5

Патч-релиз после принятой 1.0.4.

## Что изменилось

### Музыка аукциона и колеса через OBS Timer Browser Source

- Добавлен режим вывода музыки аукциона и колеса через уже существующий OBS Browser Source таймера.
- Отдельный Browser Source только для аукционного аудио не создаётся.
- В интерфейсе аукциона добавлен выбор:
  - «В приложении»;
  - «Через OBS Browser Source таймера».
- После обновления по умолчанию остаётся режим «В приложении», поэтому существующее поведение не меняется автоматически.
- В OBS-режиме локальные Qt-аудиодвижки продолжают хранить авторитетное состояние воспроизведения, но их локальный вывод становится беззвучным.
- Timer Browser Source получает текущий media ID, позицию, состояние Play/Pause, громкость профиля, Mute, Loop One и тип активной музыки.
- После перезагрузки Browser Source воспроизведение синхронизируется с текущей позицией, а не начинается с нуля.
- HTTP Range для локальных media-файлов используется существующей media-инфраструктурой.

### Единый аукционный аудиоканал

- Музыка режима «Максимальная сумма» и музыка колеса используют один и тот же Timer Browser Source.
- При переходе от аукциона к колесу тип активного аудио переключается внутри одного источника.
- Звук колеса использует тот же авторитетный `wheel_started_at` / `wheel_duration_ms`, что и визуальная анимация.
- RNG, выбор победителя и геометрия колеса не зависят от аудиотранспорта.

### Основа для будущего музыкального плеера

Добавлен общий Audio Coordinator, который определяет, какая функция InOneLine владеет музыкальным каналом.

В текущем релизе он используется аукционом. Архитектура уже предусматривает последующее подключение отдельного музыкального плеера:

- до запуска аукциона плеер сможет продолжать обычное воспроизведение;
- «Старт» или «Крутить» смогут временно передавать владение аудио аукциону;
- состояние плеера сможет быть сохранено перед паузой;
- после появления доступного для подтверждения победителя владение сможет возвращаться музыкальному плееру;
- восстановление сможет происходить на том же треке и той же позиции.

Сам полноценный музыкальный плеер в 1.0.5 ещё не добавлен.

## Что не изменилось

- RNG победителя не изменён.
- Вероятности и веса секторов не изменены.
- Геометрия секторов не изменена.
- Random.org / Random.org+ не изменены.
- SQLite schema не изменена.
- Named migrations не изменены.
- Существующая media-библиотека переиспользуется без второй системы хранения музыки.
