# InOneLine 1.0.2

## Что изменилось

Версия 1.0.2 унифицирует помощь по добавлению OBS Browser Sources.

- В разделе `Стрим / OBS` добавлена одна общая кнопка **«Как добавить виджет в OBS»**.
- Отдельные одинаковые кнопки помощи у виджета таймера и виджета правил удалены.
- Для списка лотов аукциона отдельная кнопка не добавляется: используется та же общая инструкция.
- Универсальная инструкция описывает один общий сценарий: скопировать URL нужного виджета, добавить в OBS источник `Браузер`, вставить URL, задать Width / Height и разместить источник на сцене.
- Параметры OBS `Shutdown source when not visible` и `Refresh browser when scene becomes active` остаются необязательными.

## Что не менялось

- URL и HTTP API существующих Browser Sources;
- HTML/JavaScript оверлеев;
- логика аукциона и колеса;
- данные пользователя;
- SQLite schema: **18**;
- количество named migrations: **14**.

## Проверка

Точный кандидат прошёл:

- compile/source/UI gate;
- PyInstaller build;
- Inno Setup build;
- silent install;
- frozen startup/API smoke;
- ручную Windows-проверку пользователем.

После ручной приёмки релиз продвигается без пересборки: используются те же проверенные product bytes.
