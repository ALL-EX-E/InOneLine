# InOneLine D41 — диагностика реальной разметки чата

**Основной файл:** [d41_live_dom_inspector.js](./d41_live_dom_inspector.js)

Скрипт предназначен для Chrome DevTools и не устанавливается в InOneLine. Он отслеживает изменения DOM **только** на открытой странице чата. Никаких запросов в интернет, cookies, токенов, содержимого сообщений или имён авторов в отчёте нет. Идентификаторы строк записываются как локальные случайно посоленные хеши.

1. Откройте публичный чат YouTube по адресу `www.youtube.com/live_chat?...v=...` так, чтобы сообщения были видны, либо отдельный чат Twitch.
2. Откройте файл `d41_live_dom_inspector.js` на GitHub, нажмите **Raw**, скопируйте весь текст.
3. На странице чата нажмите `F12`, откройте **Sources → Snippets → New snippet**. Вставьте код и нажмите `Ctrl+Enter`.
4. Отправьте новое тестовое сообщение, затем в Console можно выполнить `iolChatDiag.mark('sent')`.
5. Удалите именно это сообщение. Выполните `iolChatDiag.mark('deleted')`.
6. В Console запустите `iolChatDiag.stop()`. Скрипт попытается скачать JSON с названием `InOneLine_D41_youtube_dom_diagnostic.json` или `...twitch...`.
7. **Если скачивание в Chrome заблокировано:** заново запустите сниппет, повторите действия и выполните в Console `copy(iolChatDiag.stop())` — отчёт скопируется в буфер обмена. Вставьте его в текстовый файл `.json`.
8. Повторите отдельно для второй платформы, приложите оба JSON к чату.

Перед отправкой проверьте отчёты. Не прикладывайте полный HTML, HAR, cookies, скриншоты Network с авторизационными заголовками и токены.

**Важно:** этот анализатор показывает реальную DOM-разметку в Chrome, но не причины сбоев загрузки чата внутри Qt WebEngine. Для второго этапа предусмотрена отдельная диагностика во вкладке «Мультичат» в кандидатной версии.
