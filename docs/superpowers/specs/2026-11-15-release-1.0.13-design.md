# InOneLine 1.0.13 Release Design

## Intent

Publish the already merged and manually accepted Journal lifecycle corrections as a new immutable public release whose internal application and installer version is 1.0.13.

## Goals

- Build version 1.0.13 from current `main` commit `ac95aec5f795ac54c7d5fd01bc42ecf0987584c8` plus release-only metadata changes.
- Preserve the accepted behavior: a clean first launch does not create automatic Music Player or multichat-delay Journal rows; later Music Player changes and explicit Twitch lifecycle actions are visible in Journal.
- Produce one native Windows CI artifact containing `InOneLine_Setup_1.0.13.exe`, the exact official source ZIP, checklist, checksums and build information.
- Require Drive readback and a separate installed user PASS before adding the immutable publication request.

## Non-goals

- No new runtime feature or database migration.
- No modification, replacement or deletion of GitHub Release `v1.0.12` or its assets.
- No publication before the exact 1.0.13 candidate is manually accepted.

## Constraints

- `APP_VERSION` and all active installer/CI version assertions become `1.0.13`.
- `SCHEMA_VERSION` remains `21`.
- The release candidate must be built and tested by the native Windows workflow, not locally substituted.
- Publication promotes the exact accepted Actions artifact without rebuilding.

## Approaches

- **Selected: new immutable `v1.0.13` release.** Correct internal version, preserved release history and a distinct acceptance gate.
- Replace the `v1.0.12` asset: rejected because it would mutate already published accepted bytes.
- Rename the accepted 1.0.12 installer as 1.0.13: rejected because its embedded version would be false.

## Delivery

Prepare and merge a release-candidate PR only after native CI succeeds. Download the exact artifact, verify its contents and hashes, upload the installer and QA bundle to Drive, then stop for manual installed acceptance. After PASS, add a new append-only `.github/release/requests/v1.0.13.json` and let the guarded publisher create and read back the public release.
