# Сверка публичных возможностей перед 1.0.12

Дата: 13.11.2026. Публичная база — выпуск `v1.0.11`. После него принят и слит мультичат Twitch + YouTube, включая адресное исправление группировки настроек; итоговый `main` — `8a9202ef9b56b76b83d0984da18af10e8ae58785`.

## Фактическое изменение продукта

- прямое подключение по HTTPS-ссылке к веб-чату конкретной трансляции YouTube без YouTube Data API и OAuth;
- единая RAM-лента и OBS-источник Twitch + YouTube с сортировкой по времени;
- аватары, нативные emoji и события удаления YouTube;
- независимое оформление платформ и отдельный допуск новых сообщений в OBS;
- три группы настроек: общие, Twitch, YouTube, со скрытием неприменимых сервисных параметров.

Не заявляются автоматический выбор своей трансляции, OAuth-управление YouTube-каналом, чат Kick/VK Video Live или гарантированная бессрочная работа при любом изменении веб-формата YouTube.

## Выпускной gate

Номер приложения и установщика меняется на 1.0.12, схема базы остаётся 21. Кандидат обязан пройти полный native Windows CI, упаковку точного установщика и source ZIP, обратную проверку копии Google Диска и ручную установку поверх используемой версии. До явного PASS пользователя выпуск `v1.0.12` не публикуется. После PASS publisher получает неизменяемый запрос с точным artifact ID, target commit, именами, размерами и SHA-256 двух принятых файлов; пересборка не допускается.
