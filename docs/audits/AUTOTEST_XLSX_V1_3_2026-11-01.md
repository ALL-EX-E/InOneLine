# AUTO-TEST-002C — совместная XLSX-таблица (только изолированная среда)

**Разрешение:** пользователь ответил «Делаем» 01.11.2026 после принятой v1.2 CSV (37 PASS / 0 FAIL / 2 SKIP). Делаем следующий небольшой блок тестировщика, не меняя проектный runtime или очередность PERF-02B/R06. Новая ветка `audit/operator-autotest-xlsx-20261101` от принятой `audit/operator-autotest-csv-20261101`.

## Проверенное исходное поведение

- Кнопки `Создать таблицу`, `Подключить таблицу`, `Отключить` первоначально принадлежат `AuctionTab`, затем прикреплены к вкладке `Список`. Они вызывают `_shared_xlsx_create`, `_shared_xlsx_connect`, `_shared_xlsx_disconnect`.
- Создание: диалог Save XLSX → `_shared_xlsx_start_write` → реальный `FunctionWorker` → `write_shared_xlsx` (временный ZIP + atomic replace) → подключение и запись настроек пути/включения. Нельзя считать создание PASS до физического XLSX, callback, подписания настройки и проверки содержимого.
- Локальное изменение: `MainWindow.notify_game_data_changed()` вызывает `shared_xlsx_local_data_changed`, debounce timer, асинхронную запись в тот же файл.
- Внешняя замена файла: `_shared_xlsx_poll` требует две одинаковые подписи `mtime_ns+size`, далее `read_shared_xlsx`, safety-backup отдельным процессом и `db.sync_main_games_state`, при необходимости запись проекции позиций.
- Отключение останавливает таймеры, сбрасывает настройки подключения, **но не удаляет XLSX**. Повторное подключение импортирует содержимое и может заменить локальное состояние (в том числе удалить отсутствующие в файле записи). Поэтому весь цикл только на временном экземпляре.
- Предыдущие AutoTest v1.2: 14 sandbox PASS, среди них 3 CSV сценария. Непосредственные действия кнопок совместного XLSX ещё не проверялись; существующая `tools/gui_regression_smoke.py` отдельно тестирует XLSX projection/race.

## Первые четыре сценария v1.3

1. **Создание и подключение через кнопку:** `shared_xlsx_create_btn.click()`; диалог выдаёт **только** путь XLSX внутри `TemporaryDirectory`. Проверить реальный файл, данные в XLSX, состояние connection, SQLite настройки, кнопку и отсутствие worker.
2. **Локальное обновление → запись в XLSX:** изменить тестовые баллы в временной SQLite и вызвать настоящий `notify_game_data_changed`, дождаться debounce/worker, прочитать XLSX, сравнить состояние с базой и синхронизацию.
3. **Внешняя замена → импорт с резервной копией:** создать второй временный экземпляр SQLite (симуляция второго клиента), экспортировать тестовую изменённую таблицу в тот же XLSX; вызвать двойной poll; проверить импорт с изменением/добавлением записей, сохранённый backup и соответствие файл ↔ локальная БД. Не имитировать облачную доставку или реальные сетевые соединения Google Drive: этот сценарий проверяет *локальный файловый протокол совместной таблицы*.
4. **Отключение и повторное подключение:** нажать настоящий `Отключить`; XLSX сохранён, настройки сброшены; локальная тестовая правка без соединения **не меняет** файл; через кнопку `Подключить` прочитать тот же XLSX; файл снова авторитетен, локальная правка заменена, настройки восстановлены.

## Safety/приёмка

- Никаких операций с пользовательскими XLSX, Google Drive Desktop, реальной SQLite, Twitch/DonationAlerts или аккаунтами.
- Прерывание сценария должно дождаться всех worker и закрыть тестовую Qt-программу до удаления temp-файлов; Windows файловые дескрипторы обязаны закрываться. Для диагностики PASS/FAIL только test_id/duration/type и текст synthetic исключения, не пользовательские данные.
- Не модифицировать логику XLSX в `views/auction.py` и `shared_xlsx.py` без обнаруженного и согласованного дефекта; только код тестировщика, README/CI/отчёт.
- Исходные 14 сценариев остаются; ожидаемый порог **18 sandbox PASS**, затем Windows frozen EXE, регрессии, нормальное закрытие, Inno Setup, пакет/Google Drive, ручной ZIP.
- Проверки визуальной отрисовки Google Sheets, конфликта реальных сетевых клиентов, блокировки Excel, больших файлов, очистки списка и любых денежных операций — отдельные задачи.

**Статус на момент записи: план задокументирован до реализации, пользовательскую приёмку пока не заявлять.**
