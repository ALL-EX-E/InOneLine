## Точный объём подпункта A

Только два существующих способа добавления изображений центра колеса:
1. **Настройки → Аукцион → Изображение центра колеса → «Добавить файл…».**
2. **Аукцион → выбор центра колеса → «Загрузить/Добавить» локальное изображение.**

В обоих случаях стандартный Windows-файловый диалог разрешает Ctrl (отдельные файлы), Shift (диапазон) и выбор одного файла. Нажатие «Открыть» импортирует выбранные файлы последовательно в **существующую** общую библиотеку изображений центра. При успешном добавлении нескольких файлов последним выбранным файлом становится изображение текущего центра; **только оно** сохраняется как активное. Входящие данные изображения проходят прежнюю проверку/нормализацию, а дубликаты идентичного содержимого используют прежнюю content-hash дедупликацию. Не создаются новые хранилища, фоновые очереди приложения или новые форматы. URL/Twitch-изображения, ручной выбор существующего изображения, default logo, live OBS и облачная библиотека не меняют semantics.

**Не входят в подпункт A и не должны объединяться с ним:** файлы soundtrack (аукцион/колесо), фоны Stream/Timer/Auction Lots/Rules, загрузки CSV, подключение XLSX, база/полное восстановление и другие потоки. Фоны/soundtrack из общего Issue #4 требуют отдельных кандидатов и пользовательской приёмки. CSV/XLSX/restores имеют семантику одной операции над одним выбранным документом и **не превращаются автоматически** в пакетные импорты.

## Ручная Windows-проверка — провести целиком перед приёмкой подпункта A

1. **Настройки: Ctrl.** Создать три разных PNG/GIF/WebP изображения в тестовом каталоге, открыть «Добавить файл…», выбрать не соседние файлы с Ctrl и нажать «Открыть». **Ожидается:** все появляются в существующем списке, в качестве текущего центра выбран последний из успешно импортированных (по порядку, возвращённому диалогом Windows).
2. **Настройки: Shift.** Добавить диапазон изображений через Shift. **Ожидается:** все добавлены за одно «Открыть», без повторного открытия файлового диалога; UI не зависает на длительном файле.
3. **Один файл / Cancel.** Импортировать одиночный PNG, затем открыть диалог и выбрать «Отмена». **Ожидается:** одиночный импорт работает как раньше, отмена не создаёт запись и не меняет текущий центр.
4. **Повторы.** Выбрать два идентичных по содержимому изображения с разными именами; повторить импорт одного из них. **Ожидается:** существующая content-hash дедупликация, без лишних одинаковых файлов и без новых записей для байтовых копий.
5. **Частичная ошибка.** Выбрать корректный и повреждённый/неподдерживаемый файл (при необходимости сменить фильтр на «Все файлы»). **Ожидается:** корректный файл добавлен, ошибочный перечислен в сообщении; весь пакет не откатывается и рабочий центр не сбрасывается.
6. **Аукцион → центр колеса.** Открыть редактор центра на колесе, через локальное добавление выбрать 2–3 файла с Ctrl/Shift. **Ожидается:** все изображения добавлены в общую библиотеку, выбран последний удачно импортированный, окно редактора закрывается один раз только после завершения пакета.
7. **Синхронизация и сохранение.** Убедиться, что изображение центра в «Настройках», локальном колесе и OBS/предпросмотре согласовано. Переключить вкладку, закрыть и открыть программу. **Ожидается:** сохранённое выбранное изображение не меняется; ручное переключение на встроенный логотип работает.
8. **Защита существующих данных.** Проверить редактирование обычного аукциона, звук колеса, музыку плеера, фоны OBS, импорт CSV, подключение XLSX и восстановление резервных копий (без фактического destructive restore). **Ожидается:** никаких новых опций мультивыбора для однофайловых операций и никаких изменений их поведения.
