# UI-086 / P20-J — безопасное переименование временного лота после 00:00

**QA-кандидат. Не принят пользователем, не слит с `main`.** P20-I принят вручную, его 6 проверенных файлов отдельно продвигаются в `main` через PR #306 после нового полного Windows CI. Версия **1.0.8**, схема SQLite, настройки, OBS/Chromium и RNG остаются неизменными.

## Граница изолированного шага

После 00:00 в исходном аукционе **«Максимальная сумма»** пока результат `winner_selected` / `tie_break_required` предварительный и колесо не запущено, можно **переименовать только временный лот** (`games.auction_only=1`), созданный в текущем аукционе. Переименование постоянных игр и объединение игровых записей имеют иной жизненный цикл и НЕ входят в P20-J.

- Во вкладке «Проведение», если выделен временный лот, появляется отдельная компактная строка с его названием и кнопкой **«Переименовать»**. При выборе постоянного лота строка скрыта. Значение в строке после смены выделения синхронизируется с выбранным лотом.
- Новое название записывается одновременно в `games.title` и `auction_entries.snapshot_title` исходного лота. Идентификаторы, начисления, `games.sm_points`, `auction_entries.starting_sm_points / bid_sm_points / weight`, состав участников и предварительный победитель **не меняются**.
- Перед изменением проверяются строго исходный `auction_id`, предварительная стадия, отсутствие `wheel_spin_id`, архива и удаления, наличие временного `auction_only=1`, отсутствие ожидающих конвертаций исходного аукциона, внешних начислений на эту временную игру и использования той же игры другой сессией.
- Название не может быть пустым, совпадать с текущим, с существующей игрой (включая архивную или другую временную), либо с названием любой другой исходной строки этого аукциона, включая удалённый tombstone и исключённую постоянную игру. **Автоматического объединения баллов нет**: пользователь получает понятное предупреждение, данные остаются неизменными. Смена регистра своего названия возможна.
- Весь шаг — одна SQLite-транзакция с записью `change_log.auction_lot.post_expiry_temporary_rename` (старое/новое название, `no_timer_restart`). Прежний титул остаётся в аудите; `remaining_ms=0`, `remaining_seconds=0`, `finished_at`, `deadline_at` остаются прежними.
- После подтверждения результата, перехода к колесу или закрытия аукциона редактор скрыт, backend отвергает изменение. Никаких изменений постоянных игр, внешних событий, списка донатов, таймера и колеса.

## Автоматическая проверка

`tools/auction_post_expiry_temporary_rename_smoke.py` — **6 тестов SQLite/Qt**:

1. Переименование временного предварительного победителя сохраняет баллы, историю `contributions`, первоначальный и новый `snapshot_title` в аудите, статус победителя и 00:00.
2. Переименование временного бывшего не-лидера при ничьей сохраняет состав лидеров и доступность его строки в «Проведение».
3. Коллизии с постоянной, другой временной, архивной, исключённой игрой и прежним собственным названием блокируются атомарно.
4. Постоянная, чужая, удалённая игра, закрытая или колесная фаза не переименовываются.
5. Ожидающие конвертации, внешние начисления и ссылка на ту же временную игру из другого аукциона блокируют операцию без изменения данных.
6. Реальный Qt: выбор временного лота показывает редактор, переименование работает, выбор постоянного скрывает редактор, после подтверждения результата действие заблокировано.

Обязательны полный `Regression Foundation 1.0.8` Windows (P20-A–J, OBS/Chromium, GUI, frozen build, Inno Setup, silent installation/startup) и отдельный `Publication wording gate`.

## Ручной чек-лист Windows

1. Установить **P20-J** поверх принятой 1.0.8, проверить список, настройки, OBS и музыку.
2. «Аукцион → Проведение → Максимальная сумма»: дождаться 00:00, не подтверждать победителя. Создать временный лот и выделить его; появится поле с кнопкой «Переименовать».
3. Изменить название. Выделенный лот должен остаться тем же (`game_id`), баллы и предварительный результат неизменны, таймер остаётся 00:00. Проверить не-лидера при ничьей.
4. Попробовать название уже существующей постоянной игры и ранее удалённого лота. Должно быть предупреждение без объединения или изменения баллов.
5. Выбрать постоянную игру: редактор должен исчезнуть. После подтверждения победителя / перехода к колесу переименование недоступно. Проверить F5, OBS и музыку.
