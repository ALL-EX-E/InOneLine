## Изолированная задача P18-A / UI-084 (пункт 2)

Найденный дефект: `IntegrationManager.check_connection()` после проверок переписывал `enabled=True` даже если пользователь выключил интеграцию.

Принятое поведение: диагностика должна сохранить `enabled` при успешном ответе, необходимости авторизации, временной ошибке сети и прочих ошибках. Проверка ненастроенного сервиса не должна автоматически активировать его. Подключить/Переподключить остаются единственными существующими явными операциями активации. Сохранённые параметры, защищённые авторизационные данные, история и блокировка новых событий отключённого сервиса остаются прежними.

Изменения: только `streaming_manager/integrations.py`, изолированный native regression `tools/integration_diagnostic_enabled_smoke.py` и обязательный Windows CI gate. Ни одного нового источника состояния, сетевого протокола или бизнес-изменения.

Статус: КАНДИДАТ — не принят, не объединён, не выпущен. Нужны успешные Windows CI, тот же проверенный QA ZIP и ручное подтверждение пользователя. Следующая отдельная задача P18-B — доступные действия кнопок исходя из реального состояния подключения.
