# P18-G / UI-084 — убрать недостижимую надпись про отсутствие подключённых сервисов

Дата: 2026-10-19 (локальное время). Основа: принятый вручную P18-F / UI-084 (пять проверок PASS), перенесённый в `main` через PR #259 (merge `5580f4b0461b218c2d6826e506477840d11853e0`); запись о приёмке обновлена в канонических документах PR #261.

## Причина и реализация

`IntegrationManager.views()` возвращает карточки **зарегистрированных** Twitch и DonationAlerts даже до подключения. Старый `integration_empty_label` с текстом `Подключённых сервисов пока нет.` показывался только при `not views`: надпись практически недостижима и дублирует очевидное состояние карточек `Не настроено`.

В P18-G удалены только создание/добавление лишнего `QLabel` и его старое переключение в `_refresh_integrations`. **Карточки сервисов не скрывать** и не менять условия их показа при отсутствии подключения. Existing RANDOM.ORG card, Twitch/DonationAlerts authorization, status, actions, draft reward, refresh, conversion, protected credentials и source-time business семантика не меняются. Нет новой модели состояния, дополнительного UI или SQLite миграций.

Source change: `streaming_manager/views/settings.py`. Native Qt smoke `tools/integration_empty_note_smoke.py`, регистрация в Windows Regression Foundation и этот документ. Принцип: reuse first, minimal diff.

## Полная ручная проверка Windows (5 пунктов)

1. `Настройки → Интеграции` без настроенных Twitch/DonationAlerts: карточки **обоих сервисов** должны оставаться видны со статусом `Не настроено` и кнопками `Подключить`; отдельной строки `Подключённых сервисов пока нет.` быть не должно.
2. При подключённом или отключённом сервисе карточка по-прежнему видна; кнопки/статусы соответствуют состоянию, лишняя строка отсутствует.
3. Переключить `Интеграции ↔ Конвертация`, затем F5. Карточки доступны, повторного пустого текста и мерцания/пустой области нет.
4. Проверить, что RANDOM.ORG, настройки Twitch Rewards и DonationAlerts отображаются и работают как до изменения. При обычном переходе между вкладками несохранённый Twitch draft не теряется.
5. Перезапустить программу, проверить сохранность подключений, настроек, истории и базовый запуск аукциона/OBS. Старую надпись не видеть.
