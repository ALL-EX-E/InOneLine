## Точный утверждённый объём

В существующих четырёх выборах фона применяется стандартный Windows Ctrl/Shift multi-select (одно нажатие «Открыть»):

1. **Стрим / OBS → Фон основного оверлея**.
2. **Стрим / OBS → Фон виджета таймера**.
3. **Стрим / OBS → Фон виджета лотов аукциона**.
4. **Редактор правил аукциона → Фон правил**, включая модальное окно.

Все используют **один существующий каталог** `MEDIA_CATEGORY_OVERLAY_BACKGROUNDS` и прежние D26/P08 правила managed/external выбора, имени файла без учёта регистра, использования существующей записи и promotion external→managed. Режим «Копировать в программу» либо «Использовать исходный файл» выбирается **один раз для всего пакета**. Варианты хранилища и их побочные действия не меняются. Источник может быть скопирован асинхронно через существующий видео-воркер (MP4/WebM); вся выбранная коллекция импортируется последовательно, а текущим фоном соответствующего виджета становится **последний успешно добавленный/переиспользованный файл**. Остальные файлы доступны в общей библиотеке через обычный выпадающий список; настройки других виджетов не переключаются. Сохранение настроек выполняется прежними кнопками «Сохранить»; режим отложенного сохранения таймера при копировании видео сохраняется до завершения *всего* пакета.

Обычные фоны поддерживают **PNG/JPG/JPEG/WEBP/GIF/MP4/WEBM** как до изменения. Фон правил — **только PNG/JPG/JPEG/WEBP**; анимированные/видео файлы в этом окне не включаются самовольно. Один файл по-прежнему обрабатывается старым алгоритмом и сообщениями. Отменённый диалог ничего не меняет; частичные ошибки пакета показываются после обработки без отката удачных файлов.

**Вне этого подпункта:** Music Player D26 и изображения центра Issue #4/A (уже приняты), soundtrack аукциона/колеса (отдельный будущий подпункт), CSV/XLSX, бэкапы, импорты других данных, схема SQLite, установка, игровые/лотерейные функции и релиз.

## Лист ручной проверки Windows (10 пунктов)

1. **Основной фон / Ctrl.** Выбрать 2–3 раздельных PNG/JPG через Ctrl. Все видны в общей библиотеке; активен последний добавленный, фон оверлея работает.
2. **Основной фон / Shift.** Добавить диапазон изображений через Shift за один «Открыть». Проверить, что диалог выбора режима хранения показан один раз.
3. **Managed-копии.** Выбрать «Копировать в программу»: файлы физически находятся в штатной библиотеке, работают после перемещения/удаления исходников.
4. **External-ссылки.** Выбрать «Использовать исходный файл»: программа не меняет оригиналы; переимпорт одного и того же имени не создаёт дублированных записей.
5. **Дубликаты и существующая запись.** Повторить пакет из уже добавленных файлов, проверить старые сообщения/выбор и возможность external→managed без нового media ID.
6. **Фон таймера + GIF.** Выбрать несколько изображений и GIF; активен последний подходящий. Нажать «Сохранить виджет таймера», проверить OBS и предпросмотр.
7. **Фон таймера + MP4/WebM.** Выбрать минимум два видео в managed-режиме, пока копирование идёт нажать сохранение настроек таймера; только после конца пакета в настройках сохранено последнее успешное видео; не произошёл преждевременный выбор или зависание интерфейса.
8. **Фон виджета лотов.** Множественное добавление меняет только выбор для лотов, не перезаписывает активные основной фон и фон таймера.
9. **Редактор правил.** В модальном редакторе добавить 2–3 изображения одним пакетом; общий каталог обновлён, предпросмотр/черновик привязан к последнему; чужие настройки неизменны. Включить в выбор GIF через «Все файлы»: GIF отклонён для правил и показан в сообщении, допустимые изображения добавлены.
10. **Отмена / неполный пакет / перезапуск.** Отмена не меняет выбор. Пакет с повреждённым/отсутствующим файлом выдаёт сводку ошибки, но сохраняет удачные файлы. После перезапуска выбранные ранее **сохранённые** фоны остаются. Отдельно убедиться, что CSV/XLSX/восстановление не получили мультивыбор.
