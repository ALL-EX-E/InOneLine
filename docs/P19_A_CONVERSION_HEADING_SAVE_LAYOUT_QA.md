# P19-A / UI-085 — заголовок и расположение сохранения курсов

Дата: 2026-10-19 по локальному времени. Основа: вручную принятый P18-G / UI-084, promotion PR #262. Это первый отдельный небольшой шаг P19 / UI-085, без реализации остальных 6+ пунктов за раз.

## Изменено только отображение

1. В `Настройки → Конвертация` заголовок блока `Валюты` заменён на `Курсы конвертации`, потому что единицы могут быть не только валютами.
2. Существующая кнопка `Сохранить курсы` **перемещена непосредственно под динамический список курсов**, а не под очередь `Ожидают применения`. Сохранён её callback `save_conversion_settings`, стиль и выравнивание по левому краю.

Файлы: `streaming_manager/views/settings.py`, этот QA-документ, `tools/conversion_heading_save_layout_smoke.py`, Windows regression workflow. Не меняется хранение/валидация/применение курсов, расчёт баллов, типы единиц, pending-поток, статус источников, история, таймер/аукцион, OBS. Атомарное сохранение всех строк и защита draft — следующий отдельный шаг P19-B, не часть P19-A.

## Ручная проверка Windows — пять пунктов

1. `Настройки → Конвертация`: вместо `Валюты` должен быть заголовок `Курсы конвертации`.
2. `Сохранить курсы` расположена **сразу под строками курсов**, перед пояснительным текстом о валюте/единицах и до `Ожидают применения`; под таблицей нет дублирующей кнопки.
3. Сначала **записать исходный курс RUB** (при работе с реальными данными желательно иметь резервную копию). Изменить его на другое допустимое значение, нажать перемещённую кнопку, перейти на другую вкладку и обратно: сохранённое значение восстановлено. Затем **вернуть исходный курс и снова сохранить его**, чтобы не изменять реальные начисления. **Не проверять здесь атомарное сохранение разных строк — оно ещё не внедрено.**
4. Проверить `Ожидают применения`: таблица, кнопка `Применить` и пояснения остаются на месте, её содержимое и состояние не меняются из-за переноса кнопки.
5. Уменьшить/увеличить окно, нажать F5, перезапустить: кнопка остаётся под курсами, не перекрывает другие поля. Проверить отсутствие изменений в интеграциях и аукционе/OBS.

Native Qt smoke гарантирует текст заголовка, единственную кнопку, точную позицию в QVBoxLayout, прежний обработчик сохранения и устойчивость после переключения страниц/refresh.
