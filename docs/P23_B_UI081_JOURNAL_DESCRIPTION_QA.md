# P23-B / UI-081 — шаг №2: актуальное описание вкладки «Журнал»

**Изолированный QA-кандидат. Не принят вручную, не переносить в main.**

## Утверждённый объём

Единственное видимое изменение: вместо «Журнал локальных изменений. Новые интеграции позже будут писать события сюда же.» отображать в том же `QLabel` точную актуальную фразу:

**«Журнал изменений и событий программы, включая аукционы, настройки и подключённые интеграции.»**

Данные интеграций уже пишутся в общий `change_log`, поэтому прежнее «позже будут» устарело. Отдельной подписи, раздела или другого UI-контейнера не создавать.

**Не меняются:** форматирование объектов/действий/подробностей (UI-081 №3 позже), SQL, содержимое и порядок `change_log`, поиск по raw/видимым полям, debounce 250 мс, асинхронная загрузка 500 последних строк, модель пяти колонок, подсказка подробностей, F5, общая тёмная тема UI-081 №1, OBS и музыка. Версия 1.0.8, схема 19 и миграции без изменений.

## Автоматическая регрессия

`tools/journal_current_description_smoke.py` проверяет существующий `LogTab` как настоящий Qt-виджет: точное новое описание, отсутствие старого, прежние 5 колонок, readonly-таблицу, 250-мс debounce, поиск, повторное обновление. Включён в native Windows Regression Foundation вместе с предыдущими QA, реальным Chromium/OBS, Inno Setup и silent startup. Publication wording gate обязателен.

## Лист ручной проверки Windows

1. Установить exact QA ZIP поверх предыдущей 1.0.8. База, настройки, игры, история сохранены.
2. Открыть «Журнал». Сверить точную новую фразу: «Журнал изменений и событий программы, включая аукционы, настройки и подключённые интеграции.» Старой подписи быть не должно.
3. Убедиться, что тёмное чередование строк из принятого UI-081 №1 сохранилось; нет белых строк, выделение читаемо, 5 колонок на месте.
4. Проверить поиск по русскому описанию события и техническому action/ID, очистку поиска, показ последних событий и подсказку в «Подробностях».
5. Нажать F5, переключить вкладки и снова открыть «Журнал»: новая подпись не меняется, события обновляются.
6. Проверить «История аукционов», OBS и Музыку: прежняя работа без новых изменений.

После подтверждения пользователя продвинуть только ровно проверенные Git blobs в `main` с Windows CI и независимым postmerge. Далее отдельный UI-081 №3.
