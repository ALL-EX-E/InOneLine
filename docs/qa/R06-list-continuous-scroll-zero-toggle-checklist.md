# InOneLine — ручной QA PR №418: скрытая прокрутка и «Время показа = 0»

**Проверять новый кандидат, а не предыдущий PR №417.** Последний принятый PR №417 уже в main. Настройки/БД и прежний виджет Twitch сохранять. Главный источник OBS `/overlay` 2560×1440; также проверить независимые `/list-overlay` и `/combined-overlay`.

## Подготовка

1. Сделать резервную копию БД. Установить Windows QA `InOneLine_R06_Setup_CANDIDATE.exe` из проверенного ZIP PR №418. Проверить, что прежняя конфигурация сохранилась.
2. В разделе «Список» поставить «Выезд», заполнить команду Twitch (например, `!list`), настроить «Время анимации» 2,00 сек. В списке иметь 12–15 записей, чтобы часть после TOP-3 действительно прокручивалась.
3. Для совместного режима выбрать «Разделение области» и Twitch-чат «Показывать постоянно» с несколькими сообщениями. Перевести список в скрытое состояние без активной команды.

## А. Прокрутка при скрытом списке

1. После запуска оставить скрытый список не менее 10–20 секунд. Вызвать Twitch-командой: список **уже во время входа** должен показывать текущую позицию прокрутки, а не первую строку/скачок после входа. TOP-3 остаётся закреплённым.
2. При обычном времени показа 5 сек дождаться 2-секундного входа, полных 5 сек на экране и обратного 2-секундного ухода. Через 10–20 сек снова вызвать: прокрутка продолжилась, не началась заново. Повторить несколько раз и для всех направлений.
3. При длинном скрытом периоде, изменении баллов или живом обновлении данных не должно быть паузы/сброса в первую строку. Пропорциональная позиция прокрутки сохраняется при смене размеров/шрифтов. Если записей не более трёх, прокручивать нечего — это нормально.
4. Повторить для отдельного `/list-overlay` и `/combined-overlay`, а также для встроенного списка в главном `/overlay`. Другие виджеты не меняются.

## Б. «Время показа = 0»: переключение одной Twitch-командой

1. У списка выбрать «Выезд» и **0 сек.** в поле «Время показа», нажать «Сохранить», проверить сохранение после перезапуска приложения. Текст подсказки объясняет поведение 0.
2. Первая *новая* команда: список плавно выезжает с сохранённой стороны. По окончании входа он **не исчезает сам** — ждать дольше обычных 5 сек.
3. Вторая *новая* команда: плавное исчезновение по обратной траектории за то же время анимации. Третья новая команда снова показывает список, четвёртая скрывает. При повторном получении **того же самого Twitch-события** переключения нет.
4. Повторить с четырьмя направлениями. Для «Снизу» список двигается только внутри собственной верхней половины совместной области; непрерывность маски, 12px разделителя, iframe и сообщений Twitch не нарушается.
5. Отдельно проверить вторую команду **во время ещё не завершившегося выезда**: список должен развернуться из текущего кадра без рывка. Новая команда во время ухода аналогично возобновляет вход без скачка.
6. Изменение режима на «Не показывать» или «Показывать постоянно» и сохранение имеет собственные ранее принятые правила и не является повторной Twitch-командой. Новый запуск приложения сбрасывает временный latch, не меняя сохранённое 0.

## В. Регрессия при времени 1–120 секунд

1. Поставить «Время показа» 5 сек, сохранить. Первая команда: 2 сек вход → **полные 5 сек** видимости → 2 сек обратный выход.
2. **Повторная команда при времени больше 0 НЕ скрывает список:** во время полной видимости обновляет полный срок показа; во время входа сохраняет текущий вход. Никакой дополнительной анимации появления и двойного таймера.
3. Проверить обычное значение 30 сек и после перезапуска. Сохранённые шрифты, рамки, фоны, пользовательские настройки списка/чата, камера, инфоблок, самостоятельные источники и положение внешней области остаются без изменений.
