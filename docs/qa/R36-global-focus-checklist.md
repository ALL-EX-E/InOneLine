# Р36 — снятие фокуса и выделения

Проверочная сборка поверх технического аудита PR №427. Публичный выпуск 1.0.10 не заменён. Все проверки ниже относятся к Р36; полного ручного PASS предыдущего аудита они не объявляют.

1. **Заполненная таблица.** На вкладке «Список» выбрать строку, нажать Esc: выделение и текущая строка снимаются, действия для выбранной записи становятся недоступны. Данные, порядок, баллы и фильтры сохраняются. Повторный Esc ничего не меняет.
2. **Свободный фон.** Выбрать строку, поставить курсор в поиск, ввести текст. Кликнуть по свободному фону страницы: курсор ввода и выделение строк снимаются, введённый текст и результат поиска сохраняются. Повторить с Esc.
3. **Все разделы.** Проверить применимые поля и таблицы в «Публичном списке», «Музыке», «Аукционе», «Истории аукционов», «Журнале», «Стрим / OBS», «Чате Twitch» и внутренних вкладках «Настроек». Снимается выбор только видимых таблиц текущей страницы. Выбор на другой основной или внутренней вкладке сохраняется.
4. **Обычные действия.** Выбор строки мышью, двойной клик, кнопки, флажки, ползунки, ссылки, прокрутка, Enter в поиске, Tab между полями, выделение и копирование текста продолжают работать. Ctrl+Esc и Shift+Esc не используются для новой функции.
5. **Редактирование ячейки.** Во время изменения ячейки первый Esc отменяет правку обычным образом и оставляет строку выбранной; следующий Esc снимает выделение. Клик по фону при допустимой правке сохраняет её обычным способом и снимает выделение.
6. **Открытые окна.** Esc сначала закрывает открытое меню, выпадающий список или диалог, сохраняя выделение таблицы главного окна. Следующий Esc в главном окне снимает выделение.
7. **Числовые поля.** Для корректного числа Esc снимает фокус без изменения значения. Для незавершённого/недопустимого ввода Esc сохраняет текст и фокус, чтобы его можно было исправить. Клик вне поля сохраняет прежнюю штатную проверку значения Qt; в этом случае поле может вернуть последнее допустимое число.
8. **Другие вкладки и завершение.** Выбрать строки в двух вкладках, снять выделение на одной и вернуться на другую: её выбор сохранён. Закрыть и повторно открыть программу: ошибок нет; настройки и данные сохранены.

Напишите результат всего пакета Р36 или номер сценария с замечанием. Автоматические проверки не заменяют эту ручную приёмку.
