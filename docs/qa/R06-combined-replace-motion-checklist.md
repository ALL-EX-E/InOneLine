# R06 — совместная область «Замещение», полный выезд списка

Прямое решение пользователя 09.11.2026 05:20 UTC, карточка Р06/COMBINED-REPLACE-MOTION-APPROVAL-087. **Только согласованная функциональность**; отдельная ручная приёмка обязательна. Используется уже сделанное для «Разделения», список занимает 100% совместной области.

## Ручная проверка
1. Установить проверочный Windows-кандидат; в «Стрим / OBS» → «Список» включить «Выезд», команду Twitch `!list`, время анимации 2,00 сек, время показа 5 сек; чат Twitch «Показывать постоянно» с несколькими реальными сообщениями (одно длинное); совместный режим «Замещение области». Проверить самостоятельный `/combined-overlay` в браузере OBS, а затем встроенный `/overlay`.
2. Для направлений «Слева», «Справа», «Сверху», «Снизу» по очереди: чат изначально виден на **всю** совместную область. По принятой команде список плавно входит с выбранной внешней границы по **всему** общему контейнеру, визуально поверх чата; в промежуточных кадрах чат остаётся под его движущимся краем и не просвечивает сквозь полупрозрачное оформление списка; содержимое списка сразу видимо, fade нет, iframe/сообщения не исчезают.
3. После полного входа начинается **5 секунд полной видимости**, не включая 2 секунды входа. Повторная команда при положительном времени продлевает показ, не скрывает список. По истечении времени список плавно уезжает обратно с того же направления за 2 секунды, последовательно открывая чат. Общий каркас неподвижен; после ухода чат на 100%, сообщения без перезагрузки/дублирования.
4. Проверить время показа **0 секунд**: первая команда показывает список до повторной; следующая скрывает, третья снова показывает. При повторе команды во время анимации вход/выход разворачивается без скачка, сохраняет направление и захваченную длительность.
5. Проверить независимые настройки: список «Показывать постоянно» **не** замещает чат и сохраняет ранее принятое распределение; «Разделение области» не изменено, отдельные `/list-overlay` и `/multichat-overlay` действуют по прежним правилам. При смене «Разделение» ↔ «Замещение» в активном показе и нажатии «Сохранить совместный режим» сохраняется принятое **немедленное** применение без обнуления таймера.
6. Если чат «Скрывать, когда пуст», он не создаёт пустую рамку без сообщений; при сообщениях — прежняя логика видимости. Не менять opacity списка или прозрачность его фона, не двигать внешнюю совместную область.

**Результат:** после проверки сообщить «Все направления и время показа при замещении работают правильно» или конкретное наблюдаемое отклонение. Только после ручного PASS и записи в главный документ допускается merge; никаких релизов автоматически.
