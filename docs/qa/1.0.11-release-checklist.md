# Проверка установщика InOneLine 1.0.11

Новый пакет объединяет уже принятые PR №423–428. Продуктовая логика сохраняется; меняются номер версии, описание и упаковка. Автоматическая проверка не заменяет ручную приёмку именно этого установщика.

1. Создать полную резервную копию текущей программы. Установить 1.0.11 поверх используемой копии; в заголовке и настройках отображается 1.0.11, список, баллы, настройки и подключения сохранились.
2. Проверить в OBS таймер, правила и список лотов: в привязанном режиме «Выезд» общая кнопка показывает и скрывает их с выбранной стороны. Они остаются на экране до скрытия; переключение вкладок не влияет. Постоянный показ и «Не показывать» от кнопки не зависят.
3. Проверить свои отдельные команды Twitch для списка и плеера. Скрытая карточка плеера появляется на настроенное время; уже видимая не продлевается, запрещённый показ не включается.
4. Сузить окно, открыть используемые настройки: подписи кнопок доступны, лишние параметры анимации при постоянном показе скрыты. Проверить Esc/клик по фону, обычный ввод и закрытие диалогов.
5. Проверить привычный аукцион, музыку, список/чат OBS, историю и журнал; перезапустить программу и убедиться в сохранении данных и настроек.

Сообщить результат всего пакета либо номер сценария с замечанием. До положительного результата пакет остаётся кандидатом, официальный релиз 1.0.10 сохраняется. После приёмки публикуются ровно эти проверенные байты установщика и исходников, без пересборки.
