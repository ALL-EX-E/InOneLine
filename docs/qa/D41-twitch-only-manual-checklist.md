# D41 — Чат Twitch (EventSub), ручная проверка кандидата

**Область:** только Twitch через существующую авторизацию EventSub. Внутренний `MultichatState` и URL `/multichat-overlay` сохранены для совместимости и будущего расширения. Браузерные YouTube/Twitch-парсеры из отменённого PR №376 НЕ включены.

**Состояние:** ожидает ручной проверки; ни один пункт ниже не считается пройденным автоматически.

| № | Действие пользователя | Ожидаемый результат |
|---|---|---|
| 1 | Установить проверенный Windows QA candidate, открыть программу. | Программа запускается, вкладка называется «Чат Twitch», название «Мультичат» в действующем интерфейсе не встречается. |
| 2 | Открыть вкладку «Чат Twitch» без авторизации. | Выводится статус Twitch; нет поля YouTube, браузерных URL и режима браузерного Twitch. |
| 3 | Через прежний механизм авторизации Twitch подключить канал и открыть его чат. | EventSub сообщает состояние подключения; новые сообщения поступают в операторскую ленту. |
| 4 | Отправить несколько сообщений Twitch, в том числе из другого аккаунта. | Сообщения приходят в порядке получения, без дублирования и видимой надписи источника «twitch» в каждой строке. |
| 5 | Удалить сообщение в Twitch (самостоятельно или модератором). | Достоверное событие EventSub удаляет нужную запись из ленты и OBS, остальные остаются. |
| 6 | Включить/выключить «Отображать чат Twitch в OBS». | На операторской вкладке сообщения продолжают показываться; OBS отображает только сообщения при включённом флаге. |
| 7 | Использовать «Копировать URL», открыть предпросмотр и существующий OBS Browser Source. | Работает тот же `http://127.0.0.1:<port>/multichat-overlay`; уже настроенную сцену менять не нужно. Виджет подписан «чат Twitch». |
| 8 | Изменить задержку, лимит и флаг времени, закрыть и перезапустить программу. | Настройки и действующий Twitch-чат работают как прежде, значения сохраняются. |
| 9 | Отключить сеть и снова подключить Twitch. | EventSub восстанавливается; не появляется дополнительный источник браузерного чата. |
| 10 | Проверить Twitch Channel Points и уже работающий аукцион. | Награды и обработчики не затронуты переименованием чата. |
| 11 | Изменить размер окна до минимального и развернуть обратно. | Все действия доступны, принятая компактная адаптивная компоновка сохранена. |

**Порядок:** Windows CI PASS → точная сборка и QA ZIP → результаты ручного checklist → прямое «Принимаю» → merge того же проверенного кода → отдельная Windows CI. Не переходить к мультичату или YouTube без нового прямого решения.
