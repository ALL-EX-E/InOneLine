# Ручная проверка команды Twitch для плеера OBS

1. В «Стрим / OBS» → «Виджет музыкального плеера» выберите «При смене трека». Укажите команду, например `!музыка`, время показа 8 сек., «Выезд» и направление. Нажмите «Сохранить виджет плеера».
2. Откройте обычный браузерный источник плеера в OBS и запустите музыку. Когда карточка скроется, отправьте из подключённого Twitch-чата точно заданную команду. Карточка должна выехать с выбранной стороны, показать текущий трек и скрыться через заданное время. Само воспроизведение продолжается.
3. Отправьте команду, пока карточка видна после смены трека или после предыдущей команды. Карточка скрывается в прежний срок. Когда она скроется, новая команда снова вызывает показ.
4. Проверьте, что команда списка управляет списком, а команда плеера — плеером. Показ карточки должен срабатывать и при отключённом показе сообщений Twitch в OBS.
5. Выберите и сохраните «Не показывать». Команда не выводит карточку в OBS. При возвращении к «При смене трека» сохранённая команда видна в настройках. Очистите поле, сохраните и проверьте, что прежняя команда перестала срабатывать.
