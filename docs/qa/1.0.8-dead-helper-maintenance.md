## Manual-QA regression and correction

The first A6 candidate was **REJECTED**.

Rejected artifact:

  `NameError: normalize_text_key is not defined`

Root cause:
- removal of `_normalized_rule_template_name` incorrectly removed the shared `normalize_text_key` import;
- `_assert_rule_template_name_unique_conn()` still directly calls `normalize_text_key`.

Corrections:
- restored `normalize_text_key` import;
- restored `RandomOrgClient` import;
- kept both dead wrapper helpers removed;
- added permanent `tools/a6_dependency_smoke.py`.

Permanent A6 smoke covers:
- create rule template;

- normalized duplicate-name rejection;
- Random.org runtime dependency resolution.
