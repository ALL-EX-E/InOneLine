# InOneLine — адресная проверка видимой подсказки «Время показа»

Основание: ручная приёмка пользователем PR №418 от 08.11.2026 и новая просьба добавить видимое пояснение рядом с временем показа списка. Это отдельная **только UI** доработка без изменения уже принятого таймера, Twitch-команды, анимации и рендера.

1. Вкладка «Стрим / OBS», раздел «Список» → «Показ виджета: Выезд»: непосредственно **под полем «Время показа»**, до поля «Время анимации», есть хорошо читаемая серая подсказка с переносом строк: «Режим „Выезд“: 0 сек. — первая команда Twitch показывает список до повторной команды, повторная скрывает. 1–120 сек. — показ по таймеру; повторная команда продлевает показ, но не скрывает список».
2. При разных ширинах окна текст переносится, не налезает на кнопки увеличения/уменьшения и не изменяет размеры остальных контролов.
3. При выборе «Показывать постоянно» или «Не показывать» поле времени и соответствующая подсказка скрываются вместе; при возвращении «Выезд» оба появляются снова.
4. «Время показа» можно сохранить как 0 и 5 секунд; значение сохраняется после перезапуска. Команда Twitch при 0 всё так же чередует появление/исчезновение, при 5 сек повтор продлевает показ. «Время анимации» независимо.
5. Убедиться, что оформление списка, совместная область, Twitch-чат, OBS/камера/инфоблок не изменились.

**Приёмка:** «Проверил видимую подсказку времени показа. Всё работает» либо конкретное замечание. Не объединять этот UI-кандидат и не выпускать релиз до отдельного ручного PASS.
