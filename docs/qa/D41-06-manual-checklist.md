# D41-06 — ручная проверка Windows: оформление чата Twitch и OBS

**Статус: кандидат только для ручной приёмки.** Не сливать в main, не выпускать релиз до прямого подтверждения пользователя. Установить только точный установщик из успешно завершённой Windows CI этого PR. Проверки проводить на реальном Twitch-канале и OBS. Для неосуществимых сценариев отмечать «НЕ ПРОВЕРЕНО», а не PASS.

| № | Действие | Ожидаемый результат |
|---|---|---|
