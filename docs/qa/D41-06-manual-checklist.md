# D41-06 — ручная проверка Windows: оформление чата Twitch и OBS

**Статус: кандидат только для ручной приёмки.** Не сливать в main, не выпускать релиз до прямого подтверждения пользователя. Установить только точный установщик из успешно завершённой Windows CI этого PR. Проверки проводить на реальном Twitch-канале и OBS. Для неосуществимых сценариев отмечать «НЕ ПРОВЕРЕНО», а не PASS.

### D41-06 FIX3 — адресная ручная проверка кнопки «Сбросить по умолчанию»

| № | Действие | Ожидаемый результат |
|---|---|---|
| F3-1 | Открыть «Чат Twitch» → «Оформление Twitch» и уменьшить окно до 520×360 | Кнопки «Сбросить по умолчанию» и «Сохранить» обе доступны через существующую прокрутку; лента не исчезает |
| F3-2 | Установить цвет/шрифт/размер сообщений, медиафон и свечение. Нажать «Сбросить по умолчанию», в подтверждении выбрать «Нет» | Ничего не сбрасывается; местный предпросмотр, сохранённое оформление OBS и файлы фона остаются прежними |
| F3-3 | Повторно нажать кнопку и подтвердить «Да» | Все настройки оформления Twitch и общего фона возвращаются к исходным, сразу видны в локальном предпросмотре; тестовое сообщение остаётся только локально |
| F3-4 | После подтверждения сброса **не нажимать «Сохранить»**, проверить виджет OBS | OBS продолжает показывать ранее сохранённый стиль, в том числе фон, свечение и расположение карточек |
| F3-5 | Закрыть программу после сброса, выбрать «Выйти без сохранения», снова открыть | Восстанавливается ранее сохранённое оформление, а не сброшенный черновик |
| F3-6 | Повторить сброс, нажать «Сохранить» и перезапустить программу | Исходный стиль теперь сохраняется и в программе, и в OBS |
| F3-7 | Проверить фоновые файлы в библиотеке, время, значки платформ и настройки Twitch | Ничего не удалилось и не сбросилось за пределами раздела внешнего вида; Twitch-чат и OBS сообщения продолжают работать |

**FIX3 принимается отдельно:** для этого изменения нужны только F3-1…F3-7 и регрессия Windows. При любом FAIL исправлять тот же PR №380 и заново проверять затронутые сценарии. До адресного PASS не сливать и не выпускать релиз.
