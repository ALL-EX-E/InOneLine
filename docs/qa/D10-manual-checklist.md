# D10 — ручная проверка значка GitHub в «Настройках»

**Статус:** кандидат; эта инструкция не подтверждает PASS. Проверять на установленном Windows-кандидате из того же GitHub Actions artifact. Сохранить принятое состояние InOneLine, не удалять данные.

1. Открыть «Настройки → Общие» в широком окне. Внизу справа один узнаваемый значок GitHub, без текстовой кнопки; подсказка при наведении «Открыть GitHub проекта».
2. Поочерёдно открыть «Аукцион», «Интеграции», «Конвертация». Значок остаётся в том же нижнем правом углу; нет дублей и скачков.
3. Уменьшить главное окно до **520 × 360**. Повторить проверку всех четырёх подвкладок: значок не выходит за пределы окна, не закрывает вертикальный скролл и маркер изменения размера.
4. На минимальном размере в каждой подвкладке прокрутить содержимое до самого низа. Проверить, что все последние настройки, таблицы, подписи и кнопки полностью видны **над** значком, доступны мышью; значок никогда не перекрывает их.
5. Повторить предыдущий пункт при средней ширине и широком окне (включая 2560 × 1440); горизонтальной внешней полосы прокрутки нет.
6. Прокрутить страницу, затем переключить подвкладку и главную вкладку. Значок остаётся на месте, настройка и её положение не изменяются самостоятельно.
7. Проверить прежние операции в «Общие»: кнопки создания копий и открытия папок; в «Аукцион» и «Конвертация» — обычные поля и «Сохранить». Они кликабельны и работают как прежде; не требуется менять реальные настройки ради проверки.
8. Нажать значок: в браузере по умолчанию открывается ровно \`https://github.com/ALL-EX-E/InOneLine\`; InOneLine остаётся работоспособным.
9. Проверить работу клавиатуры (Tab, Enter/Space) на значке и Windows масштабирование 100/125/150 %, если доступно; значок остаётся чётким и имеет доступное имя.
10. Проверить, что другие основные вкладки, аудио, OBS и содержимое базы не получили дополнительных изменений от D10.

**Для приёмки:** сообщить PASS по всем 10 пунктам или номер пункта + снимок/воспроизведение ошибки. Не сливать кандидат в main до полного ручного PASS и явной приёмки.
