# D41-02 — Twitch Multichat — ручная Windows/OBS-проверка

Статус: **КАНДИДАТ; не принят и не выпущен**. Пакет только D41-02; Twitch и базовая OBS-лента. YouTube, оформление, сторонние смайлики, GIF — следующие отдельные задачи.

**Перед проверкой:** сохранить пользовательский резервный архив InOneLine; установить candidate поверх текущей версии согласно привычному QA-порядку, без удаления пользовательской БД. Для проверки Twitch нужен доступ к своему авторизованному каналу и тестовые сообщения в реальном Twitch-чате. Для проверок удаления нужен уполномоченный модератор. Не публиковать ключи и токены в отчёте.

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Запустить приложение; открыть «Мультичат» после «Аукциона». | Приложение запускается, компоновка на 520×360 и 2560×1440 не сломана; список других вкладок сохранён. |
| 2 | Открыть Twitch на вкладке «Настройки → Интеграции» без ранее подключённого аккаунта. | Чат ещё не получает сообщения; на вкладке «Мультичат» показан операторский статус, OBS пустой и без текста об ошибке. |
| 3 | Подключить Twitch штатным Device Code, проверить выданные разрешения. | Используется существующая интеграция; запрошено право `user:read:chat` вместе с прежними правами наград; отдельный Client Secret не требуется. |
| 4 | Если Twitch уже был подключён с правами только наград, открыть «Мультичат», затем выполнить штатное «Переподключить» в «Интеграциях». | До подтверждения новых прав показано понятное предупреждение; после переподключения чат подключается, а права на действующие награды не теряются. |
| 5 | Оставить Channel Points награды ненастроенными, отправить новое обычное сообщение в свой Twitch-чат. | Сообщение появляется во вкладке «Мультичат» и в отдельном OBS-источнике без зависимости от наград. |
| 6 | Отправить подряд несколько сообщений с разными авторами, включая текст `<script>hello</script>`. | Порядок, ники и текст верны. HTML не исполняется; нет дублирования. |
| 7 | Включить «Показывать время», затем выключить; переключить задержку с 0 на несколько секунд и обратно. | Метки времени переключаются; при 0 сообщения выводятся сразу, при задержке следуют согласованному общему буферу; уже показанное не переупорядочивается. |
| 8 | Снять «Отображать чат Twitch в OBS», отправить сообщение, затем включить обратно и отправить другое. | Вкладка получает оба; OBS не получает первое задним числом, получает новое после включения; старые сообщения OBS остаются до вытеснения. |
| 9 | Удалить одно показанное сообщение из реального Twitch-чата средствами модератора. | Соответствующее сообщение исчезает из программы и OBS, остальные не затрагиваются. |
| 10 | Выполнить Twitch-модерацию с удалением всех сообщений выбранного автора (при доступности события). | В обеих лентах исчезают сообщения только этого автора соответствующего канала. |
| 11 | При наличии прав выполнить очистку всего Twitch-чата. | Текущие сообщения данного Twitch-канала исчезают из обеих лент, сообщения других платформ не затрагиваются. |
| 12 | На время отключить интернет, восстановить его, затем отправить новое сообщение. | Соединение восстанавливается автоматически; оператор видит статус. Пропущенные за разрыв сообщения не объявляются восстановленными и задним числом не догружаются. |
| 13 | Отключить Twitch через «Интеграции», сохраняя открытым мультичат. | Новые Twitch-сообщения не принимаются; уже показанные остаются. |
| 14 | Подключить другой Twitch-аккаунт через штатное переподключение, если доступен. | Старые сообщения Twitch очищаются при подтверждённой смене аккаунта; другие платформы не затрагиваются; параметры вкладки сохраняются. |
| 15 | Настроить и использовать действующую Twitch Channel Points-награду (если канал поддерживает). | Начисления, конвертация, текущие лоты и статусы наград работают как прежде; входящие сообщения чата не начисляют баллы. |
| 16 | Проверить OBS Browser Source с URL из вкладки, закрыть/переоткрыть OBS и перезапустить InOneLine. | OBS читает единую готовую RAM-ленту, не создаёт отдельный Twitch-коннект; после рестарта текстовая история чата пуста, настройки лимита/задержки/галочки сохранены. |

При отсутствии доступа к конкретному событию модерации написать **НЕ ПРОВЕРЕНО** с причиной, а не PASS. При любом FAIL указать номер, действие, фактический результат и скриншот/лог без секретов. Не сливать и не публиковать до всех обязательных PASS и прямого «Принимаю».
