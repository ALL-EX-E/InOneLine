# Проверка установщика InOneLine 1.0.13

Кандидат 1.0.13 переносит в публичную версию уже принятые исправления журнала. Автоматическая проверка не заменяет ручную приёмку именно этого установщика.

1. Создать полную резервную копию и установить 1.0.13 поверх используемой InOneLine. В заголовке должна отображаться версия 1.0.13; список, баллы, настройки, музыка и подключения должны сохраниться.
2. На чистом профиле сразу открыть «Журнал». До действий пользователя не должно быть автоматических строк `music_player_*` и `multichat_delay`.
3. Изменить громкость или другое состояние музыкального плеера, затем открыть «Журнал». Изменение должно появиться без F5.
4. Подключить или переподключить Twitch, затем открыть «Журнал». Должна появиться строка подключения с понятным статусом и аккаунтом.
5. Убедиться, что в строках подключения нет токена, пароля, credential reference или другого секрета.
6. Проверить отключение и повторное включение Twitch: оба явных действия отображаются в журнале, а сам Twitch продолжает принимать сообщения.
7. Перезапустить программу и убедиться, что журнал, мультичат, музыкальный плеер и привычные OBS-источники работают без потери данных.

Сообщить общий результат или номер сценария с замечанием. До явного положительного результата 1.0.13 остаётся кандидатом, а официальный GitHub Release v1.0.12 и его файлы сохраняются без изменений. После приёмки публикуются ровно проверенные байты установщика и официального SOURCE ZIP без пересборки.
