# Р06 — отдельные настройки совместного режима и исправление стрелок

Статус: КАНДИДАТ, не слито, требуется Windows CI и ручной PASS.

## Что проверить на Windows

1. «Стрим / OBS → Список → Выезд»: у «Время показа» есть две **отдельные** полноразмерные кнопки ▲ и ▼, а прежние крошечные Qt-стрелки внутри текстового поля отсутствуют. Увеличение/уменьшение работает в допустимых границах 1–120 секунд, сохраняется только кнопкой «Сохранить».
2. В разделе списка по-прежнему нет «Совмещение с чатом», «Показывать чат вместе со списком» и «Длительность анимации».
3. После «Информационного блока» появился отдельный «Совместный режим (список + чат)», со своим URL `/combined-overlay`, кнопками «Копировать URL совместного режима» и «Открыть предпросмотр совместного режима».
4. У «Режим совмещения» только «Разделение области» и «Замещение области». Изменение режима без «Сохранить совместный режим» **не** должно менять открытый OBS-источник. После сохранения — должно; после перезапуска настройка восстанавливается.
5. Самостоятельный `/list-overlay` не отображает Twitch-чат. Самостоятельный `/multichat-overlay` сохраняет текущую механику и оформление. Новый `/combined-overlay` содержит список и Twitch-чат, если каждый из них видим по своим настройкам.
6. Главный `/overlay` использует тот же выбор «Разделение/Замещение», что и новый совместный URL, **но** настройки режима списка и параметры Twitch-чата по-прежнему независимы.
7. В «Замещение области» список может заменять чат только при `Выезд` и активной Twitch-команде. При `Показывать постоянно` замещения не возникает. При «Не показывать» нет пустого списка. Новых fade, slide и других анимаций не добавлено.
8. Графическая область основного `/overlay` по-прежнему располагается на прежнем месте области списка в боковой колонке. Настройки веб-камеры, информационного блока, фонов, списка и чата не затронуты.

## Ограничения этой проверки

Распределение высоты Twitch-чата при `Скрывать, когда пуст` и **первом сообщении** остаётся отдельно не согласованным. Нельзя объявлять его утверждённым или менять размер по догадке: здесь используются прежние правила вычисления высоты, без визуальных анимаций. Сначала принять отдельный раздел/UI/URL и стрелки; затем вернуться к открытому вопросу по дорожной карте.

## Автотесты

- Native Qt GUI test: два полных кликабельных ▲/▼, spinbox без native buttons, самостоятельная новая форма, copy/preview, отдельное Save, сохранение старых значений SQLite.
- HTTP/API: оба старых URL сохранились, новый /combined-overlay отдаёт HTML, состав компоновщика берётся из нового persisted key.
- Chromium: в main overlay и в новом combined URL появляется Twitch iframe; в standalone List его нет; по команде, истечению времени, переключению hidden/always и replace/split отсутствуют opacity/move анимации.
- Полная Windows regression, frozen build, Inno installer, silent install.

Программа не публикуется и PR не сливается до явной ручной приёмки.
