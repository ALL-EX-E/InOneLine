# Р06/OBS-SHOW-001 — полный чек-лист ручной проверки первого пакета

**Статус:** кандидат; ручной PASS отсутствует. **Действителен только для установщика и исходников с точно указанным candidate SHA и прошедшим Windows CI.** Не проверять на текущем релизе 1.0.8/старом EXE.

## Подготовка

Использовать тестовую копию базы, включить Twitch EventSub (на подходящем канале с разрешённым чатом), запустить InOneLine и локальный OBS API. Подготовить список минимум из восьми записей, включая TOP-3, длинное название и ненулевые баллы. Создать два OBS Browser Source: `/overlay` (рекомендованный холст 2560 × 1440) и `/list-overlay` (размер по выбору), при необходимости третий `/multichat-overlay`. Открыть оба URL отдельно и с `?preview=1`. Сохранить исходные настройки для восстановления. Менять параметры только в `Стрим / OBS → Список`, существующий общий переключатель OBS-чата — на вкладке Twitch-чата.

## Ручные проверки: действие → ожидаемый результат

1. **Обновление/совместимость.** Запустить поверх предыдущей принятой установки без изменения настроек списка. Ранее выбранные «Не показывать» или «Показывать постоянно», текущие шрифты, оформление, положение, фон и URL сохраняются; значения новых полей по умолчанию: направление **Справа**, длительность **30 сек.**, команда **пуста**, совмещение **Разделение области**, «Показывать чат вместе со списком» для отдельного URL **выключено**.
2. **Общее управление.** Изменить режим списка, направление, время и команду, нажать «Сохранить». Оба источника используют одинаковые параметры; в HTML/OBS нет дополнительных элементов редактирования. После перезапуска значения сохраняются.
3. **Три режима.** «Не показывать» скрывает список с TOP-3 на обоих источниках, Twitch-команда его не показывает. «Показывать постоянно» отображает список без команды. «Выезд» держит список скрытым до новой подходящей команды.
4. **Четыре стороны.** Последовательно проверить «Слева», «Справа», «Сверху», «Снизу». Выезд и обратный уход выполняются с сохранённой стороны, каждый **0,45 с**; виджеты, шрифты, TOP-3 и сумма не обрезаются.
5. **Команда без нормализации.** Установить `!список`. Только отдельное сообщение точно `!список` срабатывает. `!СПИСОК`, ` !список`, `!список `, `покажи !список` и `!список текст` — нет. Разрешены любые роли зрителей.
6. **Пустая команда.** Очистить поле и сохранить. Пояснение отображается оператору; команда больше не вызывает список, но текущий активный показ не отменяется. После ввода новой команды она применяется немедленно только к новым сообщениям.
7. **Таймер 1–120.** Проверить значения 1, 30, 120 секунд. После команды список виден выбранное время, затем плавно уходит. Изменение длительности во время показа **не** пересчитывает текущий отсчёт; следующая команда использует новое значение.
8. **Повторы.** Отправить команду, затем повторить во время полного показа и во время выезда. Отсчёт начинается заново; повторного полного выезда или скачка нет. Во время ухода новая команда разворачивает список из текущего положения.
9. **Один Twitch источник событий.** Вывести обе версии списка и отдельно Twitch-чат одновременно. Одна Twitch-команда вызывает показ обоих списков, а не два независимых отсчёта; сообщения не дублируются в операторском чате.
10. **Поведение при разрыве Twitch.** Запустить показ и временно отключить EventSub. Список продолжает текущую анимацию и обратный отсчёт, не застревает; старые сообщения после подключения не запускают новый выезд.
11. **Разделение области.** Список виден и чат активен: список сверху, чат ниже, различимый промежуток. Чат занимает не более половины общей области, список не перекрывается. При скрытом временном списке чат использует доступную область по своей настройке.
12. **Динамический чат.** Включить «Скрывать, когда пуст» и отправить сообщение. Область чата плавно увеличивается за **0,45 с** до размера сообщения в пределах лимита. При нескольких сообщениях во время анимации цель сразу меняется из текущей высоты без скачка, в обе стороны.
13. **Замещение области.** При активном чате вызвать временный список. Список плавно заменяет чат во всей общей области; после времени показа чат возвращается. Оформление чата и его сообщения сохранены.
14. **Горизонтальный/вертикальный переход.** При горизонтальном выезде и необходимости изменить область чата сначала плавно освобождается место за 0,45 с, затем выезжает список 0,45 с; при вертикальном — обе анимации одновременно. Если чату не нужно менять высоту, лишней задержки нет.
15. **Смена режима совмещения на ходу.** Пока список виден, переключить «Разделение»/«Замещение» и сохранить. Общий таймер не сбрасывается и не продлевается, Twitch-команда повторно не требуется; переход плавный.
16. **Изменение направления на ходу.** Если список уже полностью показан, изменение стороны не вызывает повторный показ, но влияет на будущий уход. При смене во время незавершённого выезда/ухода текущий переход завершается по старой траектории, следующее направление учитывается позднее.
17. **Смена трёх режимов на ходу.** Проверить «Выезд»→«Показывать постоянно» и обратно, а также любые согласованные переходы с «Не показывать» во время скрытого/видимого/частично показанного списка. Переходы плавные без скачков, остановки или неуместного нового таймера.
18. **Отдельный список без чата.** Выключить «Показывать чат вместе со списком» для самостоятельного `/list-overlay`. В нём только список; основной `/overlay` продолжает совмещать чат и список независимо.
19. **Отдельный список с чатом.** Включить эту настройку. У отдельного источника действуют те же режим совмещения, общий таймер и команда, но его собственные размеры OBS. Нет отдельной настройки режима для standalone и нет дубля TCP/EventSub-подключения.
20. **Глобальный переключатель OBS-чата.** В программе выключить «Отображать чат Twitch в OBS». Chat Twitch немедленно исчезает из `/multichat-overlay`, `/overlay`, `/list-overlay` (когда чат разрешён), даже при режиме чата «Показывать постоянно». Список использует всю освободившуюся область. Операторская история не очищается.
21. **Повторное включение OBS-чата.** Отправить сообщения до выключения и во время отключения, вновь включить показ. Ни те, ни другие **не** возвращаются в OBS; появляются только последующие сообщения. Команда списка работает даже при отключённом OBS-чате.
22. **Модерация Twitch.** Удаление отдельного сообщения, очистка сообщений автора и очистка канала при получении подтверждённых EventSub-событий обновляют операторский чат, самостоятельный и совмещённые OBS-чаты, не оставляют старые строки. Не сбрасывают настройки списка.
23. **Оформление/контент.** Проверить Twitch emotes, BTTV/FFZ/7TV, аватары, badge, время и общий флаг значков платформы (скрыть/показать), выбранные цвета и фон. Длинные сообщения переносятся; уменьшение области не удаляет их из буфера.
24. **Стабильность геометрии.** Сравнить положение и размер игровой рамки, веб-камеры, информационного блока до/во время/после временного вызова, в обоих способах совмещения и на каждом направлении. Они не перескакивают; боковые панели и TOP-3 не сливаются. Проверить webcam во всех четырёх углах и список «Авто/Слева/Справа».
25. **OBS и предпросмотр.** Проверить normal/`?preview=1`, несколько источников и перезапуск источника во время текущего таймера; текущий показ/отсчёт восстанавливается из состояния InOneLine, новый полный интервал не запускается от перезагрузки. Скрытие источника «глазом» и смена сцены не создают нового вызова.
26. **Регрессия другого функционала.** Убедиться, что `/music-player-overlay`, `/timer-overlay`, `/auction-lots-overlay`, колесо, правила, звук, суммы, RNG, история аукциона и пользовательские данные не изменились; прежний самостоятельный `/multichat-overlay` по-прежнему работает.
27. **Интерфейс и сохранение.** Проверить `Стрим / OBS` на минимальном окне **520×360** и большом окне; условные поля скрываются вместе с подписями, доступны при режиме «Выезд». Прокрутка/кнопка «Сохранить» доступны, внешнее окно не изменяет размер само собой.
