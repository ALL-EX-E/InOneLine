# InOneLine 1.0.8 — Regression Foundation Restoration

Status: **CANDIDATE / QA-ONLY / RUNTIME UNCHANGED**

Branch: `maintenance/qa-foundation-1.0.8`

## Purpose

Restore the already-created QA/regression foundation from the historical Google Drive QA packages instead of designing a new framework from scratch.

This first restoration pass deliberately starts with the low-risk reusable pieces:

- exact build dependency lock;
- full backup/restore regression;
- failed full-restore rollback regression;
- fresh schema/integrity gate;
- accepted-toolchain frozen build;
- frozen startup/API/Browser Source regression.

The historical ~2170-line native GUI smoke suite is retained as the next sub-pass. It is not made mandatory blindly because it contains many 0.3.x/1.0.0-era product expectations that must first be classified as either still-current contracts or intentionally superseded behavior.

## 1.0.8 adaptation

The restored checks use:

- App version **1.0.8**;
- SQLite schema **19**;
- named migrations **15**;
- D26 managed `data/soundtrack` content in full backup/restore;
- D43 Timer Browser Source audio transport;
- D26 dedicated Music Player Browser Source;
- dependency versions observed in the accepted 1.0.8 Windows build.

## Reused historical sources

The implementation is based on the earlier QA package `InOneLine_QA_INSTALLER_BUILD_R1.0.10_1.0.0.zip` preserved in the project Drive archive, especially its:

- `requirements-build-lock.txt`;
- full backup smoke;
- full restore rollback smoke;
- frozen/EXE smoke design;
- GUI regression suite, reserved for the next compatibility pass.

## Safety boundary

This branch must not modify product runtime or build-product definition paths:

- `app.py`;
- `streaming_manager/**`;
- `installer/**`;
- `requirements.txt`;
- `data/**`;
- `assets/**`.

The Windows workflow fails if any of these paths differ from `main`.

## Candidate gate

The Windows gate performs:

1. QA-only diff verification.
2. Exact dependency installation + `pip check`.
3. `compileall` for current runtime and restored QA tools.
4. Full backup/restore regression, including D26 soundtrack data.
5. Restore rollback regression with an injected filesystem failure.
6. Fresh DB quick/integrity/foreign-key/schema/migration checks.
7. PyInstaller build using the accepted 1.0.8 toolchain versions.
8. Frozen startup and API health.
9. All six Browser Source routes, including Music Player.
10. D43 Timer audio transport and D26 Music Player overlay markers.

Runtime code must not be changed merely to satisfy an obsolete historical test expectation.
