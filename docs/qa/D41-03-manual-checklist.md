# D41-03 — локальный браузерный мультичат YouTube/Twitch — Windows QA

**Только кандидат. Старые Google OAuth/Data API/list полностью отклонены.** Без подписки, платного сервера, Google Cloud/OAuth ID и внешнего браузера. Единственный браузерный компонент работает локально через Qt WebEngine. Важное юридическое замечание: сайты YouTube и Twitch ограничивают автоматизированный сбор данных; технический QA не означает разрешение платформы.

**Перед началом:** сохранить резервную копию InOneLine, установить D41-03 из прилагаемого архива, Twitch EventSub и его награды до теста оставить без изменений. Длительный 24/7 soak-тест, обрывы соединения и многосуточное восстановление будут проводиться пользователем *после* базовой ручной приёмки, во время использования; о потерянных сообщениях нельзя заявлять, что они восстановлены.

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Запустить Windows-программу и открыть «Мультичат», сверить прежний Twitch EventSub и награды. | Вкладка/виджет OBS работают, награды Twitch сохранены. |
| 2 | Открыть «Настройки → Интеграции». | **Нет** карточки или формы Google OAuth; Twitch/DonationAlerts на месте. |
| 3 | Вставить ссылку `https://www.youtube.com/live_chat?is_popout=1&v=<ID>` от своей трансляции и нажать «Применить». | Ссылка сохраняется, Qt WebEngine загружает этот чат; Google Cloud ID не нужен. |
| 4 | Аналогично проверить ссылку отдельного чата через `https://studio.youtube.com/live_chat?...&v=<ID>`. | Загружается при доступности страницы; если Studio требует логин — отметить отдельно; авторизация в браузере не равна Google Cloud OAuth. |
| 5 | Вставить `http://...`, чужой домен, обычный `watch?v=`, неверный video ID. | Понятная ошибка, старое подключение не разрушается. |
| 6 | Подключиться посреди действующего эфира с уже имеющейся историей. | Прошлые сообщения не выводятся, только новые после подключения. |
| 7 | Отправить несколько новых сообщений на YouTube. | Появляются в общей вкладке и OBS, без второго чата/задвоений; если нет — сообщить FAIL, привести скриншот без секретов. |
| 8 | Отправить одновременно сообщения на Twitch EventSub и YouTube. | Один хронологический общий поток; разные значки/графика — будущие D41 этапы. |
| 9 | Выключить YouTube в OBS и отправить сообщения, затем включить. | Во вкладке новые видны, в OBS отключённые не появляются задним числом. |
| 10 | Заменить ссылку YouTube на другой достоверный эфир. | Очистится только старая YouTube-лента; Twitch и его разрешения не затрагиваются. |
| 11 | Оставить YouTube-чат без сообщений некоторое время. | Нет ложного статуса ошибки просто из-за тишины; показанные сообщения не удаляются. |
| 12 | Выбрать «Браузерный чат» в способах Twitch. | Появляется подтверждение о возможных дублях и прекращении чтения EventSub; награды продолжают работать. |
| 13 | Отменить подтверждение. | Остался исходный EventSub-режим и прежний поток. |
| 14 | Подтвердить браузерный Twitch, вставить popup URL (`dashboard.twitch.tv/popout/u/<канал>/stream-manager/chat` или `www.twitch.tv/popout/<канал>/chat`). | Новые Twitch-сообщения приходят только через браузер; EventSub для наград сохранён. |
| 15 | Переключить Twitch обратно на EventSub с подтверждением. | Чтение Twitch через браузер прекращено; при действующих правах снова работает официальный EventSub; награды не затронуты. |
| 16 | Проверить пустой чат и содержимое с HTML-символами, изменения размеров окна 520×360 и 2560×1440, перезапустить программу. | Нет исполнения HTML как кода, нет наложений интерфейса, настройки ссылок и способа Twitch сохранены, история RAM после перезапуска пуста, OBS-виджет не перестал работать. |
