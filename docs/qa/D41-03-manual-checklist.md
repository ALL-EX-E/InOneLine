# D41-03 — YouTube multichat — полный сценарий ручной приёмки

**Статус: WINDOWS КАНДИДАТ, НЕ ПРИНЯТ / НЕ ВЫПУЩЕН.** Только YouTube-чат и связанная авторизация. Twitch, аукцион, начисления, графические emotes, темы оформления не изменяются.

Перед началом: резервная копия пользовательских данных InOneLine; установлен только D41-03 кандидат, тестовый собственный YouTube-канал с правами управления и доступом к прямым трансляциям, подключённый Twitch для сравнения. Google OAuth требует собственный **публичный Client ID типа Desktop** с включённым YouTube Data API v3. Не вводить Client Secret, не передавать в отчётах токены/коды OAuth. Если нет нужных прав или одновременных трансляций, писать «НЕ ПРОВЕРЕНО», а не PASS.

| № | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Запустить программу, открыть «Настройки → Интеграции». | Появилась отдельная карточка YouTube; прежние Twitch и DonationAlerts не исчезли. |
| 2 | Без Client ID нажать «Подключить YouTube». | Понятное сообщение о недостающем Google OAuth Client ID, никаких фиктивных подключений. |
| 3 | Указать Google OAuth Client ID типа Desktop и сохранить. | Сохраняется только публичный ID; никакого Client Secret и токенов в SQLite. |
| 4 | Нажать «Подключить», войти через официальный браузер Google. | Откроется согласие на чтение YouTube; локальный OAuth callback завершается, приложение показывает реально авторизованный канал. |
| 5 | Проверить Google-аккаунт без YouTube-канала или отменить вход. | Не выбирается произвольный канал; понятный статус, Twitch продолжает работать. |
| 6 | С подключённым аккаунтом без активной трансляции открыть «Мультичат». | YouTube ждёт эфир, ошибка/заглушка не появляется в OBS, Twitch продолжает поступать. |
| 7 | Начать единственную трансляцию с доступным YouTube-чатом. | Программа автоматически подключает именно её чат без ввода URL, начинает получать только **новые** сообщения. |
| 8 | Отправить по несколько текстовых сообщений на YouTube и Twitch. | Один хронологический поток во вкладке и OBS, корректные источники/авторы/время; обычный HTML не исполняется. |
| 9 | Выключить галочку «Отображать чат YouTube в OBS», отправить сообщение, включить и отправить новое. | Программа видит оба, OBS видит только новое после включения; старое показанное до выключения не удаляется. Twitch не затрагивается. |
| 10 | Удалить тестовое сообщение в YouTube (если Google отправляет событие удаления). | Сообщение удалено из вкладки и OBS; другие сообщения сохранены. При недоступности события — «НЕ ПРОВЕРЕНО». |
| 11 | Иметь две самостоятельные активные трансляции собственного канала до выбора. | Программа предлагает выбрать одну по названию, не подключает сразу обе; отмена оставляет YouTube в ожидании. |
| 12 | После отмены выбора оставить одну из ранее двух активных трансляций. | Автоподключения нет; оператор может повторно открыть список и подтвердить выбранную трансляцию. |
| 13 | Завершить выбранную трансляцию, оставив другую уже активной. | Ранее показанные сообщения остаются; автоматического перехода нет, нужен ручной выбор. |
| 14 | Завершить выбранную трансляцию при отсутствии других активных, позже начать одну новую. | Старые сообщения сохраняются до подключения нового эфира; новый единственный выбирается автоматически, прежние сообщения только YouTube очищаются при настоящем переходе. |
| 15 | Сымитировать отключённый чат, сетевой разрыв и переподключение Google/смену доступного YouTube-канала. | Нет случайного переключения на другой эфир, статус только оператору; после восстановления принимаются новые сообщения. Смена канала очищает только YouTube, Twitch остаётся. |
| 16 | Перезапустить приложение и OBS; проверить Qt-окно 520×360, обычный размер и 2560×1440. | RAM-история исчезла, настройки OBS/лимита/задержки остались, отмена выбора нескольких эфиров сбросилась, адаптивная компоновка и прежние функции не повреждены. |

**Завершение:** отправить номера PASS / FAIL / НЕ ПРОВЕРЕНО, при FAIL — шаг, действие, фактический результат, скриншот/лог без секретов. Не сливать в main и не публиковать до отдельного «Принимаю». Отключённый YouTube-чат и невозможность проверить Google OAuth без своего клиента не считаются автоматически выполненным сценарием.
