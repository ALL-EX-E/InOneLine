# Ручная проверка повторной оптимизации

В архиве есть оба списка проверок. Начните с CHECKLIST_MAINTENANCE.md для условных настроек.

1. Откройте программу, вкладку «Аукцион» и предпросмотр колеса в OBS. Проверьте встроенный значок, затем выберите свой значок и верните встроенный. Закройте программу и запустите её снова. Оба предпросмотра должны работать после перезапуска.
2. До старта выберите «Максимальная сумма», затем «Взвешенное колесо». Кнопка «Данные проверки» появляется для будущего вращения. В тестовом аукционе с ничьей подготовьте решающее колесо и проверьте ту же кнопку до вращения.
3. В «Публичном списке» подключите одну тестовую копию Excel, затем другую. Проверьте актуальные строки и отметку времени именно второго файла. Если второй файл уже содержит свои данные, программа заменит их публичным списком.
4. В «Публичном списке» найдите игру и нажмите Enter. До старта аукциона тот же лот выделяется в «Аукционе». F5 обновляет все данные и каталоги саундтреков.
5. В OBS-предпросмотре списка лотов включите автопрокрутку, дождитесь движения и выключите. Позиция остаётся на месте. Повторное включение продолжает движение оттуда же.
6. В «Чат Twitch» проверьте поступление сообщений с задержкой, отображение значков и тестовое сообщение при смене оформления. В «Журнале» быстро введите несколько символов. После паузы таблица показывает результаты последнего запроса.
