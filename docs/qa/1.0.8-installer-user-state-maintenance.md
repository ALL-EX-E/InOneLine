## Goal

Keep the intentional elevated installer model required by the default `C:\InOneLine` installation and mutable-directory ACLs, while removing administrative-installer ownership of per-user HKCU UI state.

The application now owns UI state in `data\ui_state.ini`. Frozen Windows builds migrate legacy per-user QSettings from the actual interactive user's Registry, preserve a recovery copy before cleanup, and then stop recreating the legacy Registry state.

## Accepted implementation

- `PrivilegesRequired=admin` remains unchanged.
- Installer HKCU ownership/cleanup is removed.
- Post-install application launch uses `runasoriginaluser`.
- UI state is stored in `data\ui_state.ini`.
- Legacy migration checks both `Registry32Format` and `Registry64Format`.
- Production `Local Streaming Tools / Streaming Manager` sources are prioritized; missing keys may be backfilled from the other view and then the reserved final-name store.
- All discovered legacy sources are copied to `data\legacy_ui_state_backup.ini` before Registry cleanup.
- Legacy sources are cleared only after the INI write and backup succeed.
- A one-time migration marker makes migration idempotent.
- `QLockFile` single-instance protection prevents multiple GUI processes from racing and overwriting shared UI state.
- Source-mode development does not migrate production Registry automatically.
