# Р06/LIST-INDEPENDENT-UI-003 — ручная проверка (кандидат, без объединённого контейнера)

Статус: только кандидат, не сливать в `main` без явного пользовательского PASS.

## Настройки

1. «Стрим / OBS → Список». Во всех трёх вариантах «Показ виджета» отсутствуют строки «Длительность анимации», «Совмещение с чатом» и галочка «Показывать чат вместе со списком».
2. Остались «Показ виджета», «Направление выезда», «Время показа», «Команда Twitch», «Положение списка», ТОП-3, оформление, фон и собственные кнопки URL/предпросмотра.
3. Изменения не применяются в OBS до нажатия «Сохранить».
4. Исторические значения `list_animation_seconds`, `list_chat_layout`, `list_with_chat` сохраняются в базе после сохранения остальных настроек; пользователь не обязан вводить их заново.

## Самостоятельный OBS-список

5. URL `/list-overlay`: сообщения Twitch не появляются ни при каких прежних настройках совмещения, даже после нового сообщения. У списка нет пустой рамки чата.
6. «Не показывать» + «Сохранить»: список исчезает сразу; не меняет opacity, не сдвигается и не оставляет пустую область сообщения.
7. «Показывать постоянно» + «Сохранить»: список появляется сразу, без fade и выезда.
8. «Выезд» + Twitch-команда: список мгновенно появляется, показывает выбранное время и мгновенно скрывается по истечении срока. Отдельная длительность показа не удалена.
9. ТОП-3, лоты/баллы, шрифты/цвета/рамки/скролл и предпросмотр прежние.

## Границы пакета

- В существующем основном `/overlay` **сохраняется прежняя временная композиция** списка и чата; это не реализация нового контейнера с третьим URL.
- Согласованный новый совместный контейнер, его размещение в основном оверлее, отдельные настройки и вопрос 50/50 при первом сообщении требуют следующего пакета после окончания уточнения поведения.
- Анимации R06 и PR №387 не трогать.
- После выполнения ручной проверки принять или назвать единственный конкретный дефект. Только после ручного PASS возможен merge и следующий шаг.
