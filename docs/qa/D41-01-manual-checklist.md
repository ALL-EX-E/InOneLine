# D41-01 — проверка кандидатного мультичата на Windows

Статус: **ОЖИДАЕТ РУЧНОЙ ПРОВЕРКИ** только после успешной автоматической Windows-регрессии и создания QA-артефакта. Пока PASS не получен, в main не сливать и релиз не публиковать.

Кандидат: черновой PR #374, `candidate/d41-chat-core-01`. Состав: RAM-ядро, задержка и лимит, базовая вкладка, локальный OBS URL через существующий HTTP-сервер. Реальные Twitch/YouTube-сообщения, все варианты оформления, аватары, эмодзи и полноценное подключение интеграций НЕ входят в этот первый кандидат.

## Защита принятой программы

Тестировать в чистой Windows VM/Sandbox или на отдельном тестовом компьютере/профиле, не поверх рабочей установки. Действующий установщик использует тот же продукт и номер 1.0.8 и может заменить установленную принятую копию. Сначала сделать независимую резервную копию пользовательских данных и убедиться, что путь/профиль теста изолирован. Не использовать рабочие Twitch/YouTube-токены для этого пакета. Не переносить данные из теста обратно в основную программу.

## Автоматическая проверка, а не ручная имитация событий

В составе CI отдельно проверяются: сортировка Twitch/YouTube сообщений по выбранной задержке, нулевая задержка, повторные event ID, удаление, смена источника, независимость OBS-галочки и переполнение RAM, безопасное отображение строк с `<script>`, выдача JSON и адаптивность Qt. В этой сборке **нет** пользовательской кнопки для генерации фиктивных сообщений и нет подключения настоящего чата; не искать эти функции.

После выполнения приложить короткий отчёт по всем пунктам 01–16, дату, точное имя QA-артефакта, скриншоты минимального/широкого окна и OBS, а также отдельные наблюдения о дефектах. Любой FAIL — возвращаемся к FIX D41-01, не продвигая код.
