# Issue #4/C — пакетное добавление музыки аукциона и колеса: Windows QA

**Статус: CANDIDATE / НЕ ПРИНЯТ / НЕ ОБЪЕДИНЁН.**

## Границы подпункта C

Два существующих выбора **«Добавить soundtrack…»** на вкладке Аукцион (музыка основного аукциона и музыка колеса). Вместо выбора одного MP3/WAV/OGG через Windows диалог можно выделить несколько с Ctrl (отдельные) или Shift (диапазон) и нажать «Открыть» один раз. Во время пакетного импорта выбранные файлы последовательно поступают в прежнюю **общую библиотеку soundtrack** (D26); дубликаты/конфликты имён обрабатываются **старым** механизмом (существующий файл / заменить / отдельная копия / отменить для конкретного файла). Режим хранения **один на пакет**: «Копировать в программу» или «Использовать исходный файл». Аудио каждого отдельного файла по-прежнему копируется существующим Qt `FunctionWorker`; все исходные файлы не загружаются в память одновременно.

После окончания всего пакета только **последний успешно импортированный файл** становится активной музыкой *того виджета, откуда был открыт диалог*. Остальные доступны в общей библиотеке через выпадающий список. Не меняется активный трек второго виджета, не меняются настройки громкости, mute, паузы, аукционного таймера, колесо RNG/весы или источник OBS. Выбор нового активного soundtrack во время действующего аукциона/вращения выполняется **один раз** штатной командой смены, а не на каждом этапе пакетного импорта. Отдельный один файл и «Отмена» должны работать по-старому.

Форматы только MP3/WAV/OGG, как было. Ошибки отдельных файлов обобщаются в одном сообщении в конце, удачные записи сохраняются; если валидных файлов нет — текущая музыка и библиотека не меняются.

**Не входят:** D26 плеер Музыка, фоны/центр колеса (Issue #4/A и B уже приняты), CSV/XLSX/backup, новая модель плейлиста (каждый виджет продолжает выбирать **одну** активную композицию), автоматическая смена треков, schema/migrations, версия/выпуск, будущие игровые или универсальные аукционы.

## Ручная проверка на Windows — все 9 пунктов

1. **Soundtrack колеса / Ctrl.** Выделить три разных MP3/WAV/OGG с Ctrl и нажать «Открыть». При режиме «Использовать исходный файл» все должны появиться в общем списке, активным в колесе станет последний выбранный файл.
2. **Музыка аукциона / Shift.** Выделить диапазон из нескольких MP3/WAV/OGG и выбрать «Копировать в программу». Дождаться завершения; все должны появиться в общем списке и штатной папке, активным для аукциона станет последний.
3. **Перекрёстное использование.** Открыть список в другом музыкальном виджете и выбрать один из импортированных файлов вручную. Убедиться, что обе библиотеки одинаковы, но выбранные треки для аукциона и колеса независимы.
4. **Повторные имена.** Добавить уже импортированные MP3/WAV/OGG в обоих режимах. Проверить исходные диалоги разрешения конфликта: использовать существующий, заменить, отдельная копия, отмена. Не должно появляться неожиданного количества записей.
5. **Асинхронное копирование.** Импортировать два достаточно больших аудиофайла в режиме копирования. Во время первого копирования активный трек не должен меняться и интерфейс должен продолжать отвечать. Оба файла должны появиться, а финальный выбор примениться только после второго.
6. **Частичная ошибка.** В «Все файлы» выбрать корректный MP3 и неподдерживаемый файл. Корректный добавляется, неподдерживаемый перечисляется в сообщении; текущий выбор обновляется на корректный. При отсутствии корректных файлов выбор не меняется.
7. **Один файл и отмена.** Одиночный выбор по-прежнему показывает старый диалог хранения и сразу применяет файл. Отмена диалога не создаёт записи и не меняет ранее выбранный soundtrack.
8. **Проверка звучания/OBS.** До/после импорта воспроизвести обычный аукцион и колесо, проконтролировать отсутствие одновременного звучания с музыкальным плеером, корректную громкость/выключение звука, отсутствие сброса таймеров и корректный вывод через выбранный OBS/локальный режим.
9. **Перезапуск и защита данных.** Перезапустить приложение. Выбранные для аукциона и колеса треки сохраняются, файлы из режима внешних ссылок не изменяются, управляемые копии работают без исходников. CSV/XLSX, резервное восстановление, игровые данные и фоновые изображения не изменились.
