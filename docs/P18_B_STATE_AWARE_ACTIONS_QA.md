## Только P18-B / UI-084 — первый пункт

На странице `Настройки → Интеграции` убираем неуместные одновременные кнопки:

- Не настроено: `Подключить <сервис>`.
- Подключено и активно: `Проверить соединение`, `Переподключить`, `Отключить`, `Удалить подключение`.
- Подключено, но отключено: `Включить`, `Удалить подключение`.
- Ошибка или требуется вход: когда отключено — `Включить`, `Переподключить`, `Удалить подключение`; когда активно — `Проверить соединение`, `Переподключить`, `Отключить`, `Удалить подключение`.

`Включить` проверяет существующие сохранённые credentials/config через уже имеющийся adapter check, не начинает OAuth и активирует только после подтверждённого `connected`. При ошибке сети/требовании нового входа оставляет disabled; `Переподключить` остаётся отдельным явным полным OAuth recovery path. Ни повторного провайдерного state store, ни изменения database schema, event processing или lifecycle P18-A.
