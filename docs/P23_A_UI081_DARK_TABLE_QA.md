# UI-081 / шаг №1 — общий тёмный стиль QTableView / QTableWidget

**QA-кандидат, не принят пользователем.** Выполнен только первый утверждённый пункт UI-081 из `docs/ACTIVE_REVIEW_LEDGER.md`.

## Реализация

- В едином `APP_STYLE` общий селектор таблиц расширен с `QTableWidget` на `QTableWidget, QTableView`.
- Использованы ровно существующие цвета: фон `#202326`, чередование `#24282b`, выделение `#295e83`, белый текст, общая рамка/сетка.
- Журнал сохраняет `QTableView + QAbstractTableModel` и включённое `setAlternatingRowColors(True)`; отдельного стиля только для Журнала нет.
- Не меняются `LogTab`, SQLite, асинхронная загрузка/поиск, сортировка, лимит 500, колонки, событие интеграции, tooltip, F5/dirty-refresh.
- UI-081 пункт №2 (устаревшая подпись), №3 (русские названия и детали) — отдельные последующие этапы. Нет release/schema/migration changes.

## Автоматические проверки

Нативная Windows Regression Foundation запускает `tools/journal_shared_dark_table_style_smoke.py` и предыдущие тесты. Тест проверяет единый CSS-селектор, сохранение всех тёмных цветов, фактические цвета обычной/альтернативной строки настоящего `QTableView` в окне, сохранение `QTableWidget`, модель пяти колонок и подсказку подробностей. Остальной полный Windows CI проверяет OBS/Chromium, freeze, Inno Setup и запуск установленной 1.0.8.

## Ручная проверка Windows

1. Установить только проверенный ZIP поверх текущей 1.0.8 и убедиться, что БД, игры, аукционы и настройки сохранены.
2. Открыть вкладку «Журнал»: обычные строки тёмные, нечётные слегка светлее, **белых полос нет**; белый текст читается.
3. Проверить выделение строк и смену выбора: синий тёмный фон, текст виден, прежние пять колонок и прокрутка сохранены.
4. Проверить поиск по старому событию, русскому названию и raw техническому слову; очистить поиск, проверить новый порядок, 500 последних строк без поиска.
5. Открыть «Список», «Аукцион», «История аукционов»: их таблицы и выделение выглядят как до обновления (общая тёмная тема).
6. F5, возврат к Журналу, детали по наведению, OBS и Музыка работают прежним способом. Текст описания Журнала **пока прежний** (будет в следующем пункте UI-081).

После ручного PASS — перенос **ровно проверенных Git blobs** в `main`, полный promotion Windows и postmerge. Никаких дополнительных UI-081 пунктов автоматически.
