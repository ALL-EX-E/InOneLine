# InOneLine 1.0.6

Функциональный релиз после принятой 1.0.5. Candidate вручную проверен и принят перед публикацией.

## Что изменилось

### Формат взвешенного колеса «Выбывание»

В режиме «Взвешенное колесо» добавлен переключаемый формат:

- «Обычное» — прежнее поведение с итоговым победителем;
- «Выбывание» — многораундовое исключение лотов.

В режиме «Выбывание»:

- каждое вращение использует тот же weighted RNG и текущие веса активных лотов;
- после остановки колеса результат показывается как «Выбывает: <лот>»;
- строка «Шанс в этом вращении» сохраняется и отражает реальную вероятность текущего раунда;
- вместо «Подтвердить победителя» используется кнопка «В архив»;
- архивирование выполняется только после явного действия пользователя;
- лот не удаляется окончательно: он переносится в существующий архив игр;
- архивный лот исключается из следующих вращений;
- после каждого архивирования колесо и проценты пересчитываются по оставшимся активным лотам;
- можно выйти из формата «Выбывание» после любого завершённого раунда и продолжить обычным взвешенным колесом;
- формат блокируется во время вращения и пока текущий результат ожидает действия «В архив»;
- последний оставшийся лот также проходит обычное вращение и может быть отправлен в архив;
- при полном выбывании всех лотов сессия завершается без итогового победителя.

OBS-оверлей не показывает внутреннюю механику архива. Для зрителя меняется только формулировка результата: «Победитель» → «Выбывает».

### Multi-spin verification

Один аукцион теперь может хранить несколько независимых проверяемых вращений.

Для каждого фактического spin сохраняется отдельный immutable snapshot:

- состав участников;
- исходные и эффективные веса;
- диапазоны RNG;
- случайное значение;
- выбранный лот;
- метод RNG;
- данные Random.org+ при наличии.

В истории аукционов каждый раунд можно просматривать и проверять отдельно.

### Совместимость со всей подсистемой аукциона

D21 интегрирован с существующими механиками:

- кнопкой «Остановить аукцион»;
- локальным большим таймером;
- Timer OBS overlay;
- Wheel OBS overlay;
- Auction Lots OBS overlay;
- D43-аудио через Timer Browser Source;
- скрытием вкладки «Аукцион»;
- восстановлением состояния после перезапуска;
- Local RNG;
- Random.org;
- Random.org+;
- историей RNG;
- существующим архивом игр.

Если лот уже определён как выбывающий, но «В архив» ещё не нажато, остановка аукциона не архивирует этот лот автоматически. Уже архивированные предыдущие лоты при этом сохраняются в архиве.

### Random.org+

Для многораундового режима каждое новое подписанное вращение использует отдельный одноразовый ticket. Предыдущие proofs не перезаписываются.
