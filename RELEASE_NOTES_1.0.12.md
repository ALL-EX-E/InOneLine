# InOneLine 1.0.12

Выпуск добавляет принятый мультичат Twitch + YouTube в полную программу InOneLine.

## Мультичат Twitch + YouTube

- YouTube подключается по HTTPS-ссылке на конкретное видео, трансляцию или pop-out чат. Платный YouTube Data API и OAuth не требуются.
- Сообщения Twitch и YouTube выводятся в одной операторской ленте и одном OBS-источнике по времени сообщения.
- Для YouTube поддерживаются аватары, нативные emoji и события удаления сообщений.
- Интервал чтения YouTube ограничен двумя секундами; при временных сетевых ошибках подключение восстанавливается с безопасной задержкой.
- Уже полученная лента сохраняется при переподключении. Каждую платформу можно отдельно допускать в OBS, не удаляя ранее показанные строки.

## Настройки и оформление

- Настройки мультичата разделены на три блока: «Общие настройки», «Twitch» и «YouTube».
- Общий блок содержит задержку, лимит, время, значки платформ, режим «Мультичат в OBS», URL браузерного источника, фон и контур.
- В блоках Twitch и YouTube находятся подключение, допуск сообщений в OBS и независимое оформление платформы.
- Если сервис отключён, его оформление и галочка OBS скрываются, но состояние и элементы подключения остаются доступны.
- Сохранение общего, Twitch- или YouTube-раздела не перезаписывает значения двух других разделов.

Схема базы остаётся **21**. Действующие данные, настройки Twitch, OBS и аукциона сохраняются при обновлении.

## Установка и проверка

Для Windows 10/11 x64. Перед обновлением рекомендуется создать полную резервную копию в настройках. Установщик прошёл полный native Windows CI и отдельную ручную приёмку; в релизе опубликованы ровно принятые файлы без пересборки.
